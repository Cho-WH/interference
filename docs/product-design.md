# 제품 설계

## 1. 목표

중고등학생이 두 파원의 간섭을 보고, 특정 지점에서 진동이 커지거나 작아지는 이유를 경로차와 연결해 설명할 수 있게 한다. 교사가 수업 중 시연하고 학생이 직접 탐색할 수 있는 웹 시뮬레이터를 만든다.

경쟁력의 중심은 **공간 속 두 경로 → 시작점을 맞춘 길이 비교 → 도착점의 진동 → 같은 P에서의 합성 진동**으로 이어지는 시각화다. 관측점의 수치를 읽는 것에 더해, 경로차가 위상차로 이어지는 과정을 움직임으로 전달한다.

초기 화면은 파동과 조작 대상이 중심이다. 선택 표시, 손잡이와 가까운 결과 표시로 다음 행동을 유도하고, 설명은 학생의 물리 이해와 조작에 필요한 내용으로 한정한다.

## 2. 확정한 핵심 범위

| 기능 | 필요한 결과 |
| --- | --- |
| 두 파원의 2D 간섭 | 순간 변위와 간섭무늬를 살펴봄. 무늬는 정상 상태에서 고정되고 전환 중에는 변화함 |
| 관측점 P 선택·이동 | 같은 P까지의 두 경로, 거리와 경로차가 함께 갱신됨 |
| 파장 조절 | 파원에서 새로 생기는 파동부터 바뀌고 변화가 공간과 P로 전달됨 |
| 파원 간격 조절 | 드래그 중 위치 미리보기, 놓으면 파동보다 느리게 실제 파원이 이동함 |
| 두 경로의 연속적인 펼치기 | 공간의 경로가 어느 비교 행으로 옮겨졌는지 추적할 수 있음 |
| 시작점을 맞춘 길이 비교 | 공간의 원래 경로와 동일한 화면 길이·파장으로 펼쳐 공통 거리와 추가 구간을 비교 |
| 도착점의 진동 비교 | 경로 끝에서 수평 보조선으로 연결된 두 성분점이 같은 순간을 보여 줌 |
| P의 합성 진동 | 두 성분 오른쪽의 합성점이 두 변위의 합으로 진동함 |
| 재생·일시 정지 | 전체 시각화가 함께 진행하거나 같은 순간에 멈춤 |
| 필요한 수치 | 두 거리, 경로차, 파장에 대한 경로차 비율을 관련 그림 가까이에서 확인함 |

초기 물리 조건은 파장 15cm, 파원 간격 30cm이며 같은 진동수·같은 초기 위상·같은 진폭의 두 파원이다. `처음으로`도 이 조건으로 복원한다. 파장 조절, 단위, 계산 및 생략한 현상은 [물리 모델](physics-model.md)을 따른다. 현재 기술 구성과 교체 경계는 [구조와 재사용](architecture.md)에 정의한다.

현재 엔진은 파원의 위치·진동 이력에 전파 시간을 적용한다. 향후 PhET 같은 격자 엔진으로 교체할 수 있도록 화면과 엔진을 공개 샘플링 계약으로 분리한다. 계산 방식을 학생용 모드 선택으로 노출하지 않는다.

## 3. 수업 중의 기본 흐름

1. P를 움직이며 큰 진동과 진동하지 않는 위치를 찾는다.
2. 두 경로를 펼쳐 공통 거리와 추가 길이를 비교한다. 공간·비교의 길이와 파장은 같은 축척이다.
3. 경로 끝과 같은 높이의 성분점, 그 오른쪽 합성점에서 두 순간 변위의 합을 관찰한다.
4. 파장·간격을 바꾸고 경로차와 간섭무늬의 관계를 다시 살펴본다.

기본 설정에서는 파원 드래그 중 목표만 미리 보고, 놓으면 파동보다 느리게 실제 파원이 이동한다. 이미 나온 파동은 과거 위치에서 퍼진다. 변화 중에는 성분과 합을 표시하되 같은 거리·단일 파장·경로차 비율 해석은 정상 상태까지 유보한다. 상세 옵션에서 중간 과정을 생략할 수 있다.

## 4. 배치와 표현에서 고정할 선택

| 선택 | 교육적 이유 |
| --- | --- |
| 공통 축척·시작점 정렬 | 같은 파의 추가 이동 길이를 비교함 |
| 같은 거리 보조점과 경로차 눈금 | 위상차의 원인을 길이 차이와 연결함 |
| 두 성분의 행 정렬과 오른쪽 합성점 | 같은 P의 두 기여와 합을 구분함 |
| 행별 0선·공통 변위 축척 | 순간 변위의 방향·크기와 대수적 합을 읽음 |
| 하나의 시계·관측점 | 높이뿐 아니라 움직임의 위상 관계를 비교함 |

실제 치수·전환 시간·반응형·입력 규격은 [학생 화면과 언어](ux-language.md), 과도 상태의 값과 경로 의미는 [물리 모델](physics-model.md)에만 정의한다.

## 5. 핵심 기능으로 할 수 있는 활동

별도 활동 엔진이나 채점 기능 없이 기본 탐색으로 가능한 수업 흐름이다.

| 활동 | 학생이 할 일 | 연결할 개념 |
| --- | --- | --- |
| 먼저 예상하고 확인하기 | P를 고르고 길이 차이로 진동을 예상한 뒤 성분과 합을 관찰 | 경로차와 도착 위상차 |
| 한 파장 더 이동하기 | 경로차가 달라도 도착 위상 관계가 같은 지점을 비교 | 경로차 전체와 파장 단위 반복 |
| 합이 움직이지 않는 곳 찾기 | 성분은 움직이지만 합은 0에 머무는 P를 찾기 | 순간 변위 0과 완전 상쇄의 차이 |
| 같은 간섭 조건 따라가기 | P를 움직이며 같은 경로차의 위치를 살펴보기 | 경로차와 간섭무늬의 공간적 연결 |
| 파장 바꾸고 다시 보기 | P를 고정하고 파장을 바꿔 추가 경로에 들어가는 파형을 비교 | 같은 경로차라도 파장에 따라 달라지는 위상차 |

핵심 조작을 먼저 완성하고, 활동 문장은 교사의 발문이나 후속 활동 자료로 활용한다. 기본 화면의 안내는 현재 조작에 필요한 내용으로 한정한다.

## 6. 후속 검토 후보와 범위 경계

### 교사 수업 모드

기존 탐색의 `교사 수업` 또는 `?mode=teacher`로 진입한다. [설계 v2](teacher-mode-design-v2.md)에 따라 8장면·23개 수동 정지 지점, A/B/C 예측·확인, 전체 화면·가림·포인터, 조건 조작과 자유 탐구 복귀, 초안 편집·부분 리허설·저장을 제공한다.

같은 예제 안에서는 조작한 P와 파장을 유지하며, 다른 예제의 입력은 현재 시각에 적용한다. 학생이 예측할 때는 결과를 유추할 필드·파형·성분·합을 일괄 가린다. 결과는 정상 상태가 된 뒤 교사가 직접 공개한다. 구현과 범위 경계는 [교사 수업 구현](teacher-mode.md)에 정리했다.

### 이후 후보

핵심 시각화가 충분히 읽히는지 확인한 뒤 선택한다. 아래 목록은 구현 약속이나 초기 조절기 목록이 아니다.

- 짧은 진동 흔적 또는 고정된 P의 시간 기록: 움직이는 방향과 위상 관계를 더 분명히 볼 필요가 있을 때 검토한다.
- 경로차에서 완전한 파장 수와 남은 부분을 구분하는 보조 표현: 전체 길이 차이를 유지하면서 한 주기의 반복을 강조한다.
- 예상한 뒤 결과를 확인하는 활동, 조건을 만족하는 지점 찾기: 기본 조작 위에 얹을 수 있는 간단한 수업 활동으로 검토한다.
- 초기 위상차·서로 다른 진폭: 동위상·등진폭의 기본 모델을 충분히 전달한 뒤 심화 범위로 검토한다.

이중 슬릿 측정, 단일 슬릿 회절, 반사·경계, 초파속 이동, 광학·소리별 정량 모델은 현재 범위가 아니다. 이동에 따른 위상 간격 변화는 현재 모델에 포함하지만 별도의 도플러 실험 UI는 제공하지 않는다. 계정·서버·활동 관리 시스템도 현재 요구에 포함하지 않는다.
