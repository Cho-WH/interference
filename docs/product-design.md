# 제품 설계

## 1. 목표

중고등학생이 두 파원의 간섭을 보고, 특정 지점에서 진동이 커지거나 작아지는 이유를 경로차와 연결해 설명할 수 있게 한다. 교사가 수업 중 시연하고 학생이 직접 탐색할 수 있는 웹 시뮬레이터를 만든다.

경쟁력의 중심은 **공간 속 두 경로 → 시작점을 맞춘 길이 비교 → 도착점의 진동 → 같은 P에서의 합성 진동**으로 이어지는 시각화다. 관측점의 수치를 읽는 것에 더해, 경로차가 위상차로 이어지는 과정을 움직임으로 전달한다.

초기 화면은 파동과 조작 대상이 중심이다. 선택 표시, 손잡이와 가까운 결과 표시로 다음 행동을 유도하고, 설명은 학생의 물리 이해와 조작에 필요한 내용으로 한정한다.

## 2. 확정한 핵심 범위

| 기능 | 필요한 결과 |
| --- | --- |
| 두 파원의 2D 간섭 | 움직이는 파동과 고정된 간섭무늬를 각각 살펴볼 수 있음 |
| 관측점 P 선택·이동 | 같은 P까지의 두 경로, 거리와 경로차가 함께 갱신됨 |
| 파장·파원 간격 조절 | 조건 변화가 공간의 간섭과 선택점의 결과에 함께 반영됨 |
| 두 경로의 연속적인 펼치기 | 공간의 경로가 어느 비교 행으로 옮겨졌는지 추적할 수 있음 |
| 시작점을 맞춘 길이 비교 | 공통 거리까지의 파형과 더 이동한 구간을 직접 비교할 수 있음 |
| 도착점의 진동 비교 | 경로 끝에서 수평 보조선으로 연결된 두 성분점이 같은 순간을 보여 줌 |
| P의 합성 진동 | 두 성분 아래의 합성점이 두 변위의 합으로 진동함 |
| 재생·일시 정지 | 전체 시각화가 함께 진행하거나 같은 순간에 멈춤 |
| 필요한 수치 | 두 거리, 경로차, 파장에 대한 경로차 비율을 관련 그림 가까이에서 확인함 |

초기 물리 조건은 같은 진동수·같은 초기 위상·같은 진폭의 두 파원이다. 파장 조절, 단위, 계산 및 생략한 현상은 [물리 모델](physics-model.md)을 따른다. 기술 선택은 [구조와 재사용](architecture.md)의 경계를 만족하는 선에서 구현 시작 시 정한다.

## 3. 수업 중의 기본 흐름

### 파동을 보고 한 지점을 고른다

실행하면 두 파원의 파동과 움직일 수 있는 P가 보인다. 학생은 화면을 누르거나 P를 끌어 관측할 곳을 바꾼다. 파원 손잡이와 P는 구별한다. 파원 간격은 손잡이나 가까운 조절기로 바꿀 수 있게 한다.

선택한 P까지의 두 경로를 표시한다. 수치는 현재 비교에 필요한 거리와 경로차를 중심으로 해당 경로 가까이에 배치한다. 파원 1·2의 색과 식별 표시는 모든 화면에서 유지한다.

### 경로를 펼쳐 차이를 본다

`경로 비교`를 열면 두 경로가 연속적으로 회전·이동해 평행한 두 행에 놓인다. 실제 공간의 P와 경로의 관계도 계속 확인할 수 있게 한다. 펼친 뒤 P를 움직이면 펼쳐진 배치를 유지하면서 현재 비교 상태를 갱신한다.

두 출발점은 같은 가로 위치다. 두 경로의 거리 축척과 파장 축척은 같다. 더 짧은 경로의 끝과 같은 거리에 해당하는 긴 경로의 지점을 수직 보조선과 속빈점으로 표시한다. 그 지점부터 실제 끝까지의 추가 길이를 강조한다.

학생이 보아야 할 관계는 다음과 같다.

- 같은 위상으로 출발한 두 파는 같은 거리에서 같은 진동을 보인다.
- 경로가 더 길면 같은 시각에 그 경로의 끝에서 읽는 위상이 달라질 수 있다.
- 추가 길이가 한 파장 늘어나면 길이는 달라져도 도착 위상 관계는 다시 같아진다.

경로차가 0일 때는 같은 위치에서 끝나며 추가 길이 표시는 사라진다. 어느 쪽 경로가 더 긴지가 바뀌어도 파원 1·2의 행 순서를 유지한다.

### 같은 P에서의 두 기여와 합을 본다

각 경로 끝에서 수평 직선 점선을 오른쪽으로 내보낸다. 첫째·둘째 성분점은 각 경로의 행 높이를 유지하며 같은 가로 위치에 놓인다. 그 아래 같은 열에 합성점을 놓는다.

각 행에 별도의 0선을 두고, 두 경로와 세 점에 공통 변위 축척을 사용한다. 필요할 때 0선에서 점까지의 변위 막대와 짧은 이동 흔적으로 크기·방향을 읽게 한다. 합성점의 최대 변위까지 같은 축척으로 표시할 공간을 확보한다.

세 점은 `P에서의 진동`이라는 한 묶음이다. 학생은 두 성분이 함께 움직이는지, 반대로 움직이는지, 합이 얼마나 진동하는지 관찰한다. 점의 높이는 순간 변위로 설명하고, 위상 관계는 계속되는 움직임으로 읽게 한다.

### 간섭무늬와 다시 연결한다

`파동 모습`과 `간섭무늬`는 공간에서 표현하는 물리량을 바꾸는 보기다. 파동 모습은 순간 변위, 기본 간섭무늬는 합성 진폭의 분포를 나타낸다. 보기 전환 중에도 재생 상태와 관측점을 유지한다.

간섭무늬가 고정되어 보여도 경로의 파형과 P의 성분점은 계속 진동한다. 완전히 상쇄되는 P에서는 두 성분점이 진동하면서 합성점은 0에 머무는 모습을 함께 보여 준다.

## 4. 배치와 표현에서 고정할 선택

| 선택 | 이유 |
| --- | --- |
| 출발점 정렬 | 같은 파가 다른 거리의 끝에서 읽힌다는 원인을 보여 줌 |
| 같은 거리의 보조점 | 추가 이동 전까지 동일한 상태를 비교할 기준이 됨 |
| 두 성분과 합의 세 행 정렬 | 경로의 행을 유지하면서 끝값을 곧은 수평선으로 옮길 수 있음 |
| 행별 0선·공통 변위 축척 | 가지런한 배치와 두 변위의 대수적 합을 함께 표현함 |
| 계속되는 진동 | 도착점의 높이뿐 아니라 움직임에서 위상 관계를 관찰함 |
| 하나의 관측점과 시계 | 경로·끝값·합이 서로 다른 조건을 보여 주는 혼동을 막음 |

위 선택은 화면 크기와 보기 전환에서도 유지한다. 경로는 시작점을 맞추고, 성분점은 각 경로의 높이에서 수평 점선으로 연결하며, 펼치는 동안에도 현재 재생 상태를 따른다. 좁은 화면에서의 배치는 [학생 화면과 언어](ux-language.md)의 원칙을 따른다.

## 5. 핵심 기능으로 할 수 있는 활동

별도 활동 엔진이나 채점 기능 없이 기본 탐색으로 가능한 수업 흐름이다.

| 활동 | 학생이 할 일 | 연결할 개념 |
| --- | --- | --- |
| 먼저 예상하고 확인하기 | P를 고르고 길이 차이로 진동을 예상한 뒤 성분과 합을 관찰 | 경로차와 도착 위상차 |
| 한 파장 더 이동하기 | 경로차가 달라도 도착 위상 관계가 같은 지점을 비교 | 경로차 전체와 파장 단위 반복 |
| 합이 움직이지 않는 곳 찾기 | 성분은 움직이지만 합은 0에 머무는 P를 찾기 | 순간 변위 0과 완전 상쇄의 차이 |
| 같은 간섭 조건 따라가기 | P를 움직이며 같은 경로차의 위치를 살펴보기 | 경로차와 간섭무늬의 공간적 연결 |
| 파장 바꾸고 다시 보기 | P를 고정하고 파장을 바꿔 추가 경로에 들어가는 파형을 비교 | 같은 경로차라도 파장에 따라 달라지는 위상차 |

핵심 조작을 먼저 완성하고, 활동 문장은 교사의 발문이나 후속 활동 자료로 활용한다. 기본 화면의 안내는 현재 조작에 필요한 내용으로 한정한다.

## 6. 후속 검토 후보와 범위 경계

핵심 시각화가 충분히 읽히는지 확인한 뒤 선택한다. 아래 목록은 구현 약속이나 초기 조절기 목록이 아니다.

- 짧은 진동 흔적 또는 고정된 P의 시간 기록: 움직이는 방향과 위상 관계를 더 분명히 볼 필요가 있을 때 검토한다.
- 경로차에서 완전한 파장 수와 남은 부분을 구분하는 보조 표현: 전체 길이 차이를 유지하면서 한 주기의 반복을 강조한다.
- 예상한 뒤 결과를 확인하는 활동, 조건을 만족하는 지점 찾기: 기본 조작 위에 얹을 수 있는 간단한 수업 활동으로 검토한다.
- 초기 위상차·서로 다른 진폭: 동위상·등진폭의 기본 모델을 충분히 전달한 뒤 심화 범위로 검토한다.

이중 슬릿 측정, 단일 슬릿 회절, 반사·경계·도플러 효과, 광학·소리별 정량 모델은 초기 범위가 아니다. 계정·서버·활동 관리 시스템도 현재 요구에 포함하지 않는다.
