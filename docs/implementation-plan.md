# 구현과 검증 상태

제품 범위는 [제품 설계](product-design.md), 계산 규칙은 [물리 모델](physics-model.md), 엔진 경계는 [구조와 재사용](architecture.md)를 따른다.

## 현재 구현

| 영역 | 제공하는 동작 |
| --- | --- |
| 전파 엔진 | 진동수·파원 위치 이력, 지연 시각 계산, 일정 진폭 중첩 |
| 파장 변경 | 발생 위상 연속성, 기존 파동 보존, 거리별 지연 반영 |
| 파원 이동 | 드래그 미리보기·놓기 확정·취소, 목표 이동, 각 파원 `0.7v` 상한 |
| 시간 | 단일 시계, 정지 중 목표 예약, 재개·페이지 숨김·초기화 |
| 부하 조절 | WebGL2 필드 계산·직접 표시, CPU 대체·GPU 복구, 처리 시간에 따른 해상도·갱신 빈도 조절 |
| 비교 | 과거 발생 위치와 현재 파원 구별, 공간·경로·끝점·합의 동일 시각 대응 |
| 전환 표시 | 과도 상태의 간섭 판정·단일 파장 비교 유보, 진폭 보기 임시 대체 |
| 모듈 경계 | `WaveEngine` / `WaveFrame`, 백엔드 독립 샘플·뷰, 한 곳에서 구현 선택 |

## 확인할 결과

### 계산·공개 계약

- 정상 상태의 `0, λ/4, λ/2, λ` 간섭 조건과 순간 변위/진폭 구별.
- 파장을 바꿔도 먼 곳의 기존 파동은 유지되고, 이동 시간이 지난 곳부터 바뀜.
- 같은 물리 시각에서 여러 번 조절하거나 초기 시각에 조절해도 과거 위상 보존.
- 지연 시각 해를 독립적인 이분법 결과와 비교.
- 빠른 목표 입력에서도 실제 속력이 `0.7v` 이하이며 목표 도착·재지정 시 위치가 연속.
- 보관한 프레임은 이후 명령·이력 정리·초기화로 바뀌지 않음.
- 공간 샘플과 펼친 공간 단면, 경로 끝과 P 성분, 두 성분의 합이 일치.
- 정상 상태에서 진폭 무늬가 고정되고, 과도 상태에서는 진폭 판정을 유보.
- CPU 기준 필드와 GPU 픽셀을 파장 변경·이동·재지정·장시간 실행·초기화·보관 프레임에서 비교. 수치 반올림에 따른 색상표 한 칸 수준의 차이만 허용.
- 고립된 지연에서는 화질을 유지하고, 지속적인 부하에서는 해상도/빈도를 낮추며 여유가 충분할 때 점진적으로 복원.

### 브라우저·화면

- 드래그 동안 실제 파원은 이전 동작을 유지하고 목표 표시만 움직임.
- 놓기 확정, Escape·포인터 취소, 키보드와 슬라이더의 목표 이동.
- 정지 중 파장·목표 입력과 재개, 초기화가 현재 보기·재생 선택을 보존.
- 정상/과도 상태 모두 경로 끝과 성분점의 수평 대응, 합성점의 대수적 합.
- 공간·비교 길이, 공통 축척, 펼치기와 반응형 배치.
- 모바일 터치·좁은 화면·가까운 파원 선택·동작 감소 설정.
- GPU 초기 미지원·셰이더 실패·컨텍스트 손실과 복구에서도 화면·물리 시각·선택한 조작값을 보존.

명령은 [README](../README.md#검증)에 둔다. 검증 결과는 완료 보고에서 실제 수행 범위로 요약한다.

## 남겨 둔 범위

PhET식 격자 엔진, 진폭 감소·장애물·회절·반사, 초파속 이동은 구현하지 않았다. 실제 Android/iOS 기기·Safari와 교실 사용성 평가는 후속 확인 대상이다. 파원 이동의 느낌과 전파 대기 시간은 수업 사용 피드백에 따라 조정하되, 속력 상한과 시간 일관성은 유지한다.
