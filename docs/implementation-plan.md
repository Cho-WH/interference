# 구현과 검증 상태

제품 범위는 [제품 설계](product-design.md), 계산은 [물리 모델](physics-model.md), 경계 계약은 [구조와 재사용](architecture.md), 화면은 [학생 화면과 언어](ux-language.md)를 따른다. 실행 명령은 [README](../README.md#검증)에 둔다.

## 현재 제공 범위

지연 위상 전파, 속력 제한 파원 이동, 미리보기/확정/취소, 전파 또는 즉시 정착, 과도 포락선, GPU 필드·CPU 대체·복구, 공통 축척의 경로 비교, 모바일 가로 배치, P 영역·걸림 보조, 세 팔레트와 상세 옵션을 구현했다.

계산·입력·표현·자원 경계를 분리하며, 새 엔진은 `WaveEngine`/`WaveFrame` 계약을 구현한다. 선택적 GPU 패킷과 캐시 힌트가 없어도 CPU 경로로 표시할 수 있다.

## 교사 수업 모드 v2

[설계 v2](teacher-mode-design-v2.md)의 단계 1~3에 해당하는 핵심 연출, 전체 수업, 편집·저장을 구현했다. [구현 문서](teacher-mode.md)에 기능과 책임을 정리한다. 회전 후 대기와 다음 클릭의 행 배치를 분리하며 파형의 크기를 유지한다. 8장면에서 예제 A/B/C를 전파 이력과 연결한다. 파장 변경은 B의 P를 유지한 공간 복귀·기존 파장으로 예측·두 배 변경과 재생·공간 관찰·재펼침·이전과 현재 눈금 비교 순서로 진행한다. 같은 경로차가 1λ₀에서 ½λ로 바뀌며 보강에서 상쇄로 이어진다.

관련 단위 검사: `experiment-controller.test.ts`, `lesson-runner.test.ts`, `lesson-storage.test.ts`, `teacher-layout.test.ts`, `teacher-observation.test.ts`. 공개 가림·예제 직접 이동·편집 리허설·반응형과 표시 일치는 `browser/teacher.spec.ts`에서 다룬다. 공통 뷰와 명령 경계를 바꾸었으므로 일반 모드 브라우저 검사도 영향 범위다.

수치 애니메이터와 SVG/CSS가 기존 프레임 루프에서 자세를 읽는다. 물리 시계와 독립된 교체 가능한 표현 계층을 유지하며 외부 런타임 의존성은 추가하지 않았다. 실제 교실 투사·학습 효과·Safari와 실제 모바일 기기는 후속 확인 대상이다. 브라우저 자동 검사와 실제 UI 점검은 완료 보고에서 실행 여부를 구별한다.

## 변경 영역별 확인

푸시·PR·수동 배포의 자동 검사는 `npm run build`의 타입 검사·빌드와 `npm run test:smoke`의 최소 실행 확인으로 한정한다. 최소 실행 확인은 빌드된 일반·교사 화면 각각에서 화면 로딩, 렌더러 초기화, 프레임 진행, 실행 예외 유무만 확인한다. 물리 조건·화면 크기별 배치·수업 전 과정은 반복하지 않는다.

아래 표는 기능을 수정할 때 선택할 검사 목록이며 매 푸시 실행 목록이 아니다. 수정한 책임과 직접 영향을 받는 소비처에 필요한 단위·브라우저 검사만 실행한다. 관련 없는 안정된 모듈은 생략한다. 실행 생략을 요청받으면 변경 내용과 미실행 사실을 기록한다.

### 검사 유지 기준

검사마다 놓치면 생기는 사용자 오류와 독립적인 기대 결과가 있어야 한다. 과거 버그를 재현하는 검사는 관련 기능을 수정할 때 재사용하되, 같은 오류를 다른 검사에서 충분히 잡는다면 합친다. 물리 조건·전파 이력·입력 보존·공개 순서·화면 잘림·실패 복구는 해당 책임을 변경할 때 확인할 계약이다.

- 수치와 상태 규칙은 단위 검사에서 다루고, 브라우저에서는 실제 입력·배선·그리기에서 추가로 생기는 오류를 확인한다. 문구 분기를 검사하려고 전체 수업을 반복 재생하지 않는다.
- CI 기기의 정확한 실측 FPS를 통과 조건으로 삼지 않는다. 프레임 상한과 시간 처리는 결정적인 시각 입력으로 검사하고, 브라우저에서는 CPU 대체와 목표 주기 연결을 확인한다.
- CSS의 높이·폭 계산식을 기대값으로 복사하지 않는다. 콘텐츠가 화면 안에 있고 조작부가 가려지지 않는지 확인한다.
- 기준 이미지와 비교하지 않는 성공 화면 캡처와 일회성 캡처용 장면 생성은 자동 검사에서 제외한다. 필요할 때 별도로 촬영한다.
- 교사 화면의 축척은 실제 수업 연결 검사와 정지 프레임의 SVG 기하 검사로 나누어 확인한다. 같은 공개 단계를 다시 왕복하며 동일한 축척만 검사하는 별도 시나리오는 두지 않는다.

## 남은 범위

- PhET식 격자 엔진, 진폭 감소·장애물·회절·반사, 초파속 이동은 미구현이다.
- 실제 Android/iOS 기기·Safari와 교실 사용성은 후속 확인 대상이다.
- FHD 배율을 적용한 CSS 너비 1280/1536px, 브라우저 높이 600px부터의 데스크톱 배치·글자·펼친 영역 수용은 `browser/desktop-fit.spec.ts`에서 확인한다. 실제 OS 권장 배율은 기기 설정을 따른다.
- 공개 테스트용 실행 오류 안내와 수동 진단 복사를 제공한다. 배포 후 실제 호스팅의 파일 로드/캐시와 실제 기기의 장시간 사용은 별도로 확인한다. 원격 오류 수집은 아직 연결하지 않았다.
- CSS 창 크기 범위를 바꾸면 `sceneFieldEnvelope`와 배치 검사를 함께 검토한다. 현재는 지원 레이아웃의 극값으로 이력을 예약한다.
- 새 엔진은 성분 분리·경로 의미·정상 판정·포락선·즉시 정착·정규화를 별도로 정의해야 한다. 코드 교체 지점만으로 그 물리적 의미까지 자동 호환되는 것은 아니다.
