# 구현 순서

각 단계는 실제로 조작하고 관찰할 수 있는 결과까지 연결한다. 그 결과에 필요한 계산·화면·입력을 함께 구현한다. 아래 완료 조건 중 구현하거나 바꾼 기능과 직접 영향을 받는 기능에 해당하는 항목만 확인한다.

1~4단계의 첫 수업용 MVP를 구현했다. 실행·검증 명령은 [README](../README.md#검증)를 따른다.

| 단계 | 현재 구현 |
| --- | --- |
| 1 | 두 파원·P 이동, 파장·간격 조절, 파동/진폭 보기, 재생·정지 |
| 2 | 회전·이동으로 경로 펼치기, 공통 축척·시작점, 같은 거리·추가 경로 |
| 3 | 수평 점선, 세 행의 성분·합성 진동, 행별 0선과 공통 변위 축척 |
| 4 | 터치·키보드·드래그, 360px 배치, 항상 접근할 수 있는 재생·비교 조작 |

대표 물리 관계 12개와 브라우저 통합 시나리오 4개를 확인했다. 실제 교실 사용성 평가와 Android/iOS 실기기 확인은 후속 사용에서 진행한다. 아래 완료 기준은 이후 변경에서도 유지한다.

## 1단계 — 관측할 수 있는 두 파원의 간섭

### 만들 결과

- 두 파원과 움직일 수 있는 관측점 P를 표시한다.
- 기본 물리 모델, 공통 시계, 입력 상태를 연결한다.
- 파장·파원 간격을 바꾸고 P까지의 두 거리와 경로차를 확인한다.
- 순간 파동 모습과 합성 진폭에 따른 간섭무늬를 전환한다.
- 재생과 일시 정지가 실제 파동에 적용된다.

이 단계에 필요한 계산·좌표 변환·입력·그리기를 실제 동작하는 작은 단위로 만든다. 이후 단계는 완성된 단위를 재사용하며 필요한 책임을 추가한다.

### 완료 조건

- P 이동과 조건 변경이 실제 두 거리 및 간섭 결과에 반영된다.
- 한 순간의 변위가 0인 곳과 합성 진폭이 0인 곳이 구별된다.
- 보기 전환 중에도 공통 시각·관측점·재생 상태가 이어진다.
- 초기 물리 계산은 [물리 모델](physics-model.md)의 대표 간섭 조건으로 확인한다.

## 2단계 — 실제 경로에서 시작점 정렬 비교로

### 만들 결과

- 선택한 두 경로가 연속적으로 펼쳐지는 `경로 비교` 동작을 연결한다.
- 파원별 행 순서, 시작점 정렬, 공통 거리·변위 축척을 적용한다.
- 같은 거리 보조점과 추가 경로 강조를 표시한다.
- 펼친 상태에서도 P 이동과 파장 변경이 이어서 반영된다.

### 완료 조건

- 같은 물리 상태와 시각을 기준으로 전환 전후 실제 거리와 경로 끝의 위상이 일치한다.
- 긴 경로가 바뀌어도 파원의 식별과 행 순서가 유지된다.
- 경로차 0에서 불필요한 추가 구간이 사라지고, 한 파장 차이에서는 실제 길이 차이가 남는다.
- 재생 중에는 전환 과정에서도 파동이 계속 진동한다.

## 3단계 — 도착점과 합성 진동 연결

### 만들 결과

- 각 경로 끝에서 수평 직선 점선으로 같은 열의 성분점을 연결한다.
- 두 성분 아래에 합성점을 배치하고 행별 0선과 공통 변위 축척을 적용한다.
- 공통 점·0선·막대 요소로 표현을 조합한다. 변위 막대는 읽기에 도움이 되는 방식으로 적용한다.
- `P에서의 진동`과 `파원 1 / 파원 2 / 두 파의 합`으로 같은 P의 관계를 드러낸다.

### 완료 조건

- 각 경로 끝과 대응하는 성분점이 같은 순간의 같은 변위를 보인다.
- 합성점이 두 성분의 대수적 합이며, 결과 행은 두 성분과 같은 변위 축척으로 최대 진폭까지 표시한다.
- 완전 상쇄 조건에서 성분점은 진동하고 합성점은 0에 머문다.
- 연결선은 같은 순간의 끝값과 성분점을 잇는 수평 점선이고, 실제 파형은 각 물리 경로의 끝까지 표시된다.

## 4단계 — 수업에서 조작하기 쉽게 다듬기

### 만들 결과

- 좁은 화면에서 정렬과 읽기 쉬운 크기를 함께 확보한다.
- 터치, 키보드, 누르기·드래그의 대응 동작을 정리한다.
- 학생용 용어, 값과 단위, 선택 표시, 기본 화면의 정보량을 다듬는다.
- 실제 사용에서 발견한 가림·오해·조작 문제를 수정한다.

### 완료 조건

- P의 선택 표시와 가까이 있는 `경로 비교` 조작부만 보고 두 동작을 이어 갈 수 있다.
- 작은 화면에서도 두 출발점, 추가 길이, 세 진동의 대응을 구별한다.
- 이름·모양·행 순서가 색과 함께 의미를 전달하고, 일시 정지와 주요 조작을 쉽게 찾는다.
- 학생 화면의 안내는 물리 개념과 조작에 필요한 내용으로 한정하며, 변위·진폭·위상에 관한 문구가 실제 표시와 맞는다.

이 단계까지가 첫 수업용 버전의 범위다. 후속 후보는 핵심 시각화를 실제로 사용해 본 뒤 필요에 따라 선택한다.

## 변경별 확인 범위

[AGENTS.md](../AGENTS.md)의 검증 원칙을 적용한다. 변경된 책임과 직접 영향을 받는 사용처에 확인 범위를 한정한다. 변경이 여러 책임에 걸치면 해당 행의 범위를 합쳐 각 확인을 한 번씩 수행한다. 범위는 구체적인 영향이나 확인된 실패 원인이 있을 때 넓힌다.

| 변경한 부분 | 필요한 확인 |
| --- | --- |
| 설계 문서 | 바뀐 내용의 일관성, 관련 문서 링크 |
| 학생 문구 | 용어와 의미, 영향을 받는 글자 배치 |
| 한 화면의 배치 | 바뀐 배치와 직접 영향을 받는 조작; 반응형이면 문제가 생길 수 있는 대표 폭 |
| 공통 점·막대·입력 | 바뀐 공통 요소와 직접 사용하는 화면 |
| 물리식·단위·간섭 판정 | 바뀐 식의 대표 사례와 결과를 소비하는 표시 |
| 공통 시계·상태 연결 | 재생·일시 정지·재개와 영향을 받는 화면의 같은 시각 대응 |
| 빌드·배포 설정 | 실제로 변경한 실행·빌드·배포 경로 |

순수 계산의 회귀 오류가 실제로 우려될 때 작은 자동 검증을 둔다. 정렬·문구 변경은 해당 화면 관찰로 충분히 확인되면 검증을 마친다. 빌드나 검증 명령은 구현이 생긴 뒤 실제 사용하는 도구와 실행 가능한 명령에 맞춰 기록한다.

## 작업을 마칠 때

- 요청 범위의 동작 또는 문서가 완성되었는지 확인한다.
- 설계 결정이 바뀌었다면 그 정의를 소유하는 문서를 갱신한다.
- 바뀐 내용, 실제 확인한 범위, 남은 구현상의 제한을 간단히 보고한다.

검증 결과는 완료 보고에 필요한 범위로 요약하고, 다음 단계에서는 완성된 공통 요소를 재사용한다.
