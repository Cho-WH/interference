# 물리 모델 — 이력이 있는 두 파원의 전파

물리량과 계산의 의미를 이 문서에서 정의한다. 교체 가능한 엔진 계약은 [구조와 재사용](architecture.md), 표시와 조작은 [학생 화면과 언어](ux-language.md)를 따른다.

## 1. 범위와 의도적인 단순화

- 균일한 매질, 일정한 파동 속력 `v`, 같은 진폭·초기 위상의 두 파원을 다룬다. 내부 단위는 m, s, rad다.
- 현재 엔진은 파원의 과거 진동을 이동 시간만큼 늦춰 읽는 **일정 진폭의 지연 위상 모델**이다. 1차원 진행파의 위상을 거리별로 배치한다. 엄밀한 2차원 점파원 파동방정식의 해나 수면 유체 시뮬레이션은 아니다.
- 거리에 따른 진폭 감소, 이동에 따른 진폭 증폭, 반사·경계·장애물·회절·분산은 생략한다. 각 파원의 기여는 `±A`, 합은 `±2A` 범위다.
- 파장·파원 위치의 변경은 유한한 속력으로 퍼진다. 이미 생성된 파동을 현재 조건으로 다시 쓰지 않는다. 이동 중에는 방향에 따른 위상 간격 변화, 즉 도플러 효과가 나타난다.
- 첫 화면과 초기화 직후에는 초기 파원이 과거부터 진동한 정상 상태를 제공한다. 파동을 처음 켜는 과도 현상은 별도 기능이다.

## 2. 발생 이력과 도착 시각

파원 `i`의 과거 위치를 `Sᵢ(τ)`, 누적 진동 위상을 `ψ(τ)`, 관측점과 현재 시각을 `P,t`라 한다. 각 파원에서 다음 조건을 만족하는 발생 시각 `τᵢ ≤ t`를 찾는다.

```math
|P-S_i(\tau_i)|=v(t-\tau_i)
```

```math
y_i(P,t)=A_i\sin(\psi(\tau_i)+\phi_i),\qquad y_{합}=y_1+y_2
```

같은 위치·시각의 두 변위를 더한다. 파면은 발생 당시 위치를 중심으로 팽창하며, 파원을 옮겨도 이전 파면의 중심은 이동하지 않는다.

파장이 `λ`일 때 발생 진동수는 `f=v/λ`다. 파장 변경 시 이전까지의 누적 위상을 유지하고 이후 기울기 `dψ/dt=2πf`만 바꾼다. 파원 파장은 새로 생성되는 파동의 설정값이며, 전환 중 공간 전체의 단일 파장을 뜻하지 않는다.

### 계산 방법

- 진동수 변경 이력은 시각·누적 위상·이후 진동수의 구간으로 저장한다.
- 실제 파원 궤적은 시각과 두 위치의 열로 저장하고, 인접 기록 사이를 등속 직선으로 해석한다.
- 실제 이동 속력이 항상 `v`보다 작으므로, 한 관측점에 대한 발생 시각→도착 시각 대응이 단조롭고 해가 하나다.
- 도착 시각으로 궤적 구간을 이진 탐색한 뒤 그 구간의 이차방정식을 풀어 발생 시각을 구한다. 정지 구간에서는 `τ=t-r/v`다.
- 도메인의 대각선 이동 시간보다 오래된 이력은 그 직전 기준 기록 하나를 남기고 제거한다. 샘플링 범위는 모델 도메인 내부다. 이미 반환한 프레임의 이력은 이후 삭제나 초기화로 바뀌지 않는다.

이는 연속 궤적을 짧은 선분으로 근사하고 각 선분의 지연 시각을 해석적으로 구하는 방식이다. 마우스 이동 자체를 물리 궤적으로 사용하지 않는다.

## 3. 파원 이동과 시간

- 입력 상태의 파원 위치는 **목표 위치**, 엔진 프레임의 위치는 **실제 위치**다. 드래그 미리보기는 둘과 별개다.
- 손을 떼거나 키보드로 목표를 확정하면 현재 위치에서 목표로 이동한다. 두 파원은 중앙선에 대해 대칭으로 움직인다.
- 각 파원의 최대 속력은 `0.7v`. 거리 비례 감속과 속도 완화로 부드럽게 이동하고, 목표를 넘어가지 않는다. 가까운 목표에 안착하는 마지막 구간도 속력 상한을 지킨다.
- 이동 적분의 최대 간격은 `1/60 s`. 위치 이력의 선분 속력도 `0.7v` 이하로 유지한다. 프레임이 늦어져도 물리 경과 시간을 버리지 않는다.
- 재지정은 실제 현재 위치에서 새로 출발한다. 이전 궤적은 보존하고 속도 완화를 다시 시작한다. 위치는 연속이며, 재지정 순간 속도의 연속성까지 보장하지 않는다.
- 시계는 하나다. 일시 정지하면 시간·발생 위상·실제 이동·전파가 함께 멈춘다. 정지 중 목표 지정은 예약하고, 파장 변경은 재개 이후 새 진동에 적용한다.
- P를 옮기는 것은 관측 위치 변경이며 물리 시간을 진행시키지 않는다. 화면 전환·펼치기·동작 감소 설정도 물리 시간을 바꾸지 않는다.

## 4. 정상 상태와 전환 상태

P에 최신 조건이 두 파원에서 모두 도착했고 파원이 정지해 있으면, 고정된 도착 위상차로 합성 진폭을 구할 수 있다.

```math
\Delta\theta=(\phi_2-\phi_1)-\frac{2\pi}{\lambda}(r_2-r_1),\qquad
A_{합}=\sqrt{A_1^2+A_2^2+2A_1A_2\cos\Delta\theta}
```

등진폭·동위상 발생에서 경로차 `nλ`는 최대 보강, `(n+1/2)λ`는 완전 상쇄다. 경로차 `0,λ/4,λ/2,λ`의 합성 진폭은 `2A,√2A,0,2A`다. 작은 부동소수점 잔여만 공통 허용 오차로 제거한다.

| 상태 | 제공하는 값 |
| --- | --- |
| P가 정상 상태 | 두 순간 변위·합, 도착 위상차, 합성 진폭, 간섭 판정 |
| P가 변화 중 | 두 순간 변위·합; 합성 진폭·정상 상태 위상차는 `null`, 판정은 `transient` |
| 공간 전체가 정상 상태 | 시간에 고정된 합성 진폭 분포 표시 가능 |
| 공간 일부가 변화 중 | 순간 변위 또는 도착 위상 포락선 분포 표시; 정상 상태의 진폭 판정은 유보 |

판정은 보수적으로 최신 조건의 도착을 기다린다. 파장 변경 직후 아직 옛 정상 상태가 남아 있어도 새 설정으로 보강·상쇄를 확정하지 않는다. 파원 이동 중에는 정상 상태 판정을 하지 않는다.

`상세 옵션`의 변화 방식은 두 보기에 공통으로 적용한다. `파동 변화 과정 생략`을 끄면(기본값) 발생 이력을 유지하고, 이 토글을 켜면 켜는 시점과 파장·파원 위치 확정 시 현재 시각·발생 위상을 보존한 채 최종 상태로 정착시킨다. 미확정 위치는 별도 정상 상태 프레임으로 미리 보고 취소할 수 있다. 보기 전환과 초기화는 선택한 옵션을 유지하며, 보기 전환 자체는 엔진을 정착시키지 않는다. 정착 시 위치 이력을 목표 위치 하나로, 위상 이력을 현재 진동수의 기준 기록 하나로 교체하고 이동 속도를 0으로 만든다. 공간 위상은 `ψ(t) − 2πr/λ + φᵢ`다.

순간 합성 변위가 0이라는 사실만으로 상쇄 간섭이라 부르지 않는다. 서로 다른 발생 진동수나 위치의 파동이 섞인 동안에는 고정된 합성 진폭을 가정하지 않는다.

### 변화 중의 간섭무늬

현재 백엔드에서 `amplitude` 필드는 각 위치에 실제 도착한 위상 θ₁, θ₂를 이용한 `|A₁ exp(iθ₁) + A₂ exp(iθ₂)| / (A₁+A₂)`다. 고정된 동일 진동수에서는 정상 합성 진폭과 일치한다. 변화 중에는 이 모델의 위상 포락선이며, 한 주기 동안의 최대 변위나 시간 평균 에너지를 뜻하지 않는다. P의 합성 진폭·보강·상쇄 판정은 기존처럼 유보한다. CPU와 GPU는 같은 지연 위상을 사용하며 정상 상태로 넘어갈 때 수식이 연속된다.

## 5. 공간 경로와 펼친 파형

- 정지·정상 상태에서는 현재 파원에서 P까지의 선분이 경로다.
- 이동의 영향이 남아 있으면 **P에 지금 도착한 파동의 과거 발생 위치**에서 P까지 선분을 표시한다. 실제 파원 손잡이와 과거 발생 위치를 구별한다.
- 선분 위의 파형은 각 공간점에서 **현재 시각**에 그 파원이 만드는 변위를 다시 샘플링한 공간 단면이다. 한 파동 덩어리의 과거 이동 궤적을 그린 곡선이 아니다.
- 선분 끝 P의 값과 오른쪽 성분점은 반드시 같다. 합성점은 같은 P의 두 값의 합이다.
- 공간 선분과 펼친 선분은 같은 거리 축척과 길이를 사용한다. 펼치기는 샘플을 회전·이동해 배치하며 물리값을 바꾸지 않는다.
- 전환 중에는 같은 거리에서 같은 위상이라는 일반화와 단일 파장 눈금이 성립하지 않을 수 있다. 같은 거리 보조점·추가 구간 강조·`Δr/λ`·한 파장 눈금을 유보한다. 도착 거리 자체는 계속 표시한다.
- 공간 전체가 정상 상태가 되면 원래의 시작점 정렬·같은 거리·추가 경로·단일 파장 비교를 복원한다.
- 최소 허용 파장과 이동 속력 상한을 고려해 전환 중 압축된 파형도 샘플링한다. 파원 ID·색·행 순서, 공통 변위 축척은 항상 유지한다.

## 6. 다른 엔진으로 교체할 때

PhET와 같은 격자 파동방정식 엔진은 별도 백엔드로 추가한다. 일정 진폭 가정·지연 시각·해석적 발생 위치를 UI 계약으로 강제하지 않는다. 격자 엔진은 공간 단면의 기준점을 현재 파원으로 제공할 수 있으며, 실제 발생 경로를 추적하지 않는다면 그 의미를 명시해야 한다. 진폭 감소나 `±2A`를 넘는 응답을 도입하면 진폭·표시 범위 계약도 함께 개정한다. 구현하지 않은 엔진을 지원 완료로 간주하지 않는다.
