# 물리 모델

이 문서는 모든 화면이 공유하는 계산과 물리적 의미를 정의한다. 각 화면은 공통 계산부의 결과를 받아 표현한다. 화면 배치와 문구는 별도 설계 문서에서 다룬다.

## 1. 모델 범위와 단위

- 균일한 매질에서 두 점 파원이 같은 진동수의 사인파를 내보내는 정상 상태를 다룬다. 기본값은 같은 진폭 `A > 0`, 같은 초기 위상 `φ₁ = φ₂ = 0`이다.
- 경로차에 따른 간섭을 분명히 비교하도록 거리에 따른 진폭 감소를 생략한다. 반사, 경계, 회절, 분산, 파원 이동에 따른 도플러 효과, 파동을 켠 직후의 과도파는 초기 범위에 포함하지 않는다. 실제 수면의 유체 운동 전체를 계산하는 모델은 아니다.
- 내부의 위치·거리·파장·변위는 SI 단위, 시간은 초, 각도는 라디안으로 저장하고 계산한다. 화면의 거리 표시는 cm 또는 파장에 대한 비율로 변환하고, 픽셀 좌표는 그리기 단계에서 구한다.
- 파동의 속력 `v`는 고정하고, 파장 `λ > 0`에서 진동수 `f = v/λ`를 구한다. 파장을 조절하면 진동수는 이 관계에 따라 함께 갱신한다.
- 재생 속도는 시계의 진행 배율이다. 이를 바꿔도 `v`, `λ`, `f` 또는 간섭 조건은 바뀌지 않는다.

## 2. 공통 계산

두 파원을 `S₁`, `S₂`, 관측점을 `P`라 한다. `y`는 매질의 변위이며 지도에서의 세로 위치 좌표와 구별한다.

$$
r_i=\lVert P-S_i\rVert,\qquad
k=\frac{2\pi}{\lambda},\qquad
\omega=2\pi f
$$

공통 시간 위상을 `ψ(t)`로 두면 각 파의 변위와 합성 변위는 다음과 같다. 진동수가 일정할 때 `ψ(t)=ωt+ψ₀`이므로 통상의 진행파 식과 같다.

$$
\theta_i(P,t)=\psi(t)-kr_i+\phi_i
$$

$$
y_i(P,t)=A\sin\theta_i(P,t),\qquad
y_{\mathrm{합}}(P,t)=y_1(P,t)+y_2(P,t)
$$

중첩은 **같은 장소, 같은 시각의 변위의 대수적 합**으로 계산한다. 두 성분의 부호를 포함해 더한 결과를 합성점과 색상 표현에 전달한다. 이 원리는 [OpenStax의 파동 중첩 설명](https://openstax.org/books/university-physics-volume-1/pages/16-5-interference-of-waves)을 따른다.

파원에서 거리 `s`인 경로상의 파형도 같은 계산을 사용한다.

$$
y_i(s,t)=A\sin\bigl(\psi(t)-ks+\phi_i\bigr),\qquad 0\le s\le r_i
$$

따라서 경로 끝의 값 `y_i(r_i,t)`는 항상 `P`에서 그 파가 만드는 변위와 같다. 2D 파동장, 펼친 경로, 끝값 비교 화면은 한 시각의 공통 계산 결과를 받는다.

## 3. 경로차와 위상차

파원 번호를 기준으로 다음 부호를 고정한다. 경로 길이가 역전되어도 파원 번호와 색을 유지한다.

$$
\Delta r=r_2-r_1,\qquad
\Delta\theta=\theta_2-\theta_1
=(\phi_2-\phi_1)-k\Delta r
$$

- 내부 계산은 부호 있는 `Δr`와 `Δθ`를 보존한다. 기본 조건에서 두 번째 경로가 길면 두 번째 파의 도착 위상이 늦어진다.
- 학생에게 보여 주는 경로차의 크기는 `|Δr|`로 표시할 수 있다. 어느 경로가 더 긴지는 두 경로와 강조 구간으로 드러낸다. 내부 위상 계산에는 부호 있는 `Δr`를 사용한다.
- `|Δr|/λ = n + q`에서 정수 `n`은 완전한 파장의 개수, `0 ≤ q < 1`은 남은 파장의 비율이다. 길이 비교에는 전체 경로차 `(n + q)λ`를 유지한다. `1λ`와 `0λ`는 길이가 다르지만 도착 위상 관계는 같다.
- 위상 관계를 비교할 때만 `Δθ`를 한 바퀴 범위로 정규화한다. 정규화한 각도와 누적 경로차를 서로 다른 양으로 유지한다.

같은 진폭·같은 초기 위상의 두 파에 대해서는 다음 조건을 사용한다. [OpenStax의 두 경로 간섭 조건](https://openstax.org/books/university-physics-volume-3/pages/3-1-youngs-double-slit-interference)과 같다.

| 경로차의 크기 | 도착 위상 관계 | 합성 진폭 |
| --- | --- | --- |
| `nλ` | 같은 위상 | `2A` — 보강 간섭의 최대 |
| `(n + 1/2)λ` | 반대 위상 | `0` — 완전한 상쇄 간섭 |
| 그 사이 | 중간 위상차 | `0`과 `2A` 사이 |

여기서 `n`은 0 이상의 정수다. 조건 판정에는 원래 정밀도의 계산값을 사용하고, 반올림은 수치를 표시하는 단계에 적용한다.

## 4. 순간 변위, 진폭, 위상의 구별

고정된 `P`의 합성 진폭은 다음과 같다.

$$
A_{\mathrm{합}}(P)
=\sqrt{2A^2+2A^2\cos\Delta\theta}
=2A\left|\cos\frac{\Delta\theta}{2}\right|
$$

- 비교 화면의 세 점은 `y₁`, `y₂`, `y합`이라는 **순간 변위**를 나타낸다. 점의 현재 높이를 설명할 때는 변위라는 용어를 사용한다.
- 완전한 상쇄 간섭은 고정점의 합성 진폭 `A합 = 0`으로 판정하며, 이때 모든 시각에 `y합 = 0`이다. `y합 = 0`인 한 순간은 진동 중 평형 위치를 지나는 순간일 수도 있다.
- 같은 높이에서도 올라가는 중인지 내려가는 중인지에 따라 위상이 다를 수 있다. 위상 관계는 계속되는 진동이나 짧은 이동 흔적으로 읽을 수 있게 한다.
- 합성 진폭이 0이면 합성파의 위상은 정의되지 않는다. 위상각을 계산하는 기능이 생기면 이 경우를 각도 값과 구별해 처리한다.
- 부동소수점 오차로 남은 극소 진폭과 수치적으로 정확한 0을 구분하기 위한 허용 오차는 공통 계산부에서 정한다. 모든 화면은 그 계산부의 간섭 판정을 공유한다.

## 5. 경로를 펴도 유지할 관계

- 두 경로의 시작점은 같은 가로 위치에 정렬한다. 파원에서부터의 거리 `s`를 공통 축척으로 표시하고, 두 끝점은 각 경로의 실제 길이에 해당하는 위치에 둔다.
- 기본 조건에서는 두 경로의 같은 거리 `s`에서 변위와 위상이 같다. 짧은 경로의 끝에 해당하는 거리를 긴 경로에도 표시한다. 그 지점부터 긴 경로의 실제 끝까지가 추가 이동 거리다.
- 경로를 펴는 애니메이션은 화면 좌표만 바꾼다. 실제 거리·경로차·파장을 유지하고, 파동 위상과 진행 시각은 공통 시계의 현재 값을 계속 따른다.
- 두 경로 및 세 행의 변위 표시는 같은 축척을 사용한다. 각 행의 0선은 서로 다른 화면 높이에 있어도 된다. 합성점에는 `±2A`까지 표시할 공간을 확보한다.
- 경로 끝에서 오른쪽 점까지의 수평 점선은 **같은 순간의 값을 복사하는 보조선**이다. 보조선은 곧은 점선으로 그리고, 그 길이와 관계없이 오른쪽 점에 경로 끝의 현재 변위를 즉시 표시한다.
- 아래 합성 행에는 `P`에서의 두 성분 변위를 더한 값을 표시한다. 두 공간 경로는 각 파원의 기여를 보여 주는 별도 경로로 유지한다. 시간 그래프를 추가할 경우 공간 경로와 축의 의미를 구별한다.

## 6. 시간과 위치 변경

- 물리 시계는 하나다. 실제 경과 시간에 재생 배율을 적용하고 `Δψ = ωΔt`로 시간 위상을 누적한다. 모든 화면은 이 공통 시계의 위상을 전달받는다.
- 파장을 바꾸어 `ω`가 바뀌어도 누적된 `ψ`는 유지한다. 새 조건의 정상 상태를 즉시 다시 계산하며, 변경 정보가 매질을 통해 퍼져 가는 과정을 모사하지 않는다.
- 기본적으로 파동은 계속 진동한다. 경로 펼치기, 관측점 선택, 비교 화면 전환 중에도 현재 재생 상태를 유지한다. 사용자가 일시정지하면 모든 물리 화면의 시간 위상이 함께 멈춘다.
- 일시정지 중 `P`를 움직이면 같은 시각의 다른 공간값을 보여 준다. 이 변화는 진동 시간이 흐른 결과가 아니다.
- 재생 중 `P`를 끌면 시간 변화와 위치 변화가 함께 반영된다. 고정점의 진동 기록을 표시한다면 관측점 변경 시 기존 기록과 분리하고, 각 기록이 나타내는 위치를 유지한다.

## 7. 파동장과 간섭무늬

| 표시 대상 | 계산하는 양 | 시간에 따른 의미 |
| --- | --- | --- |
| 순간 파동 모습 | 부호 있는 `y합/(2A)` | 마루·골·평형 위치가 계속 바뀜 |
| 간섭무늬 | 기본값 `A합/(2A)` | 고정된 조건에서는 진폭의 공간 분포가 유지됨 |
| 제곱량을 사용하는 별도 표현 | `A합²/(4A²)` | 진폭 제곱의 상대 분포이며 진폭과 같지 않음 |

- 기본 간섭무늬는 합성 진폭을 표시한다. 제곱량을 선택하는 표현이 추가되면 표시 대상의 이름과 범례도 바꾼다. 매질에 대한 별도 가정 없이 이를 절대적인 에너지나 측정된 빛의 세기로 부르지 않는다.
- 정적인 간섭무늬에는 합성 진폭 또는 그 제곱의 분포를 사용한다. `|y합|` 또는 `y합²` 한 프레임에는 순간적으로 0인 위치와 항상 진폭이 0인 위치가 섞이므로, 시간에 따라 달라지는 순간값과 고정된 진폭 분포를 구별한다.
- 서로 다른 조건의 진폭을 비교할 수 있도록 모든 화면에서 고정된 기준 `2A` 또는 `4A²`로 정규화한다.
- 공통 계산부에서 구한 물리량을 색에 대응시킨다. 두 표현을 함께 제공할 때도 순간 변위와 진폭의 범례를 각각 해당 표현에 연결한다.

## 8. 변경과 관련된 검증 예

아래 항목에서 변경한 계산·표현과 직접 관련된 검증을 선택한다. 문구 수정이나 배치 변경은 해당 내용과 영향을 받는 화면을 확인한다.

| 변경한 부분 | 확인할 핵심 관계 |
| --- | --- |
| 간섭 계산 | 기본 조건에서 경로차의 크기가 `0, λ/4, λ/2, λ`일 때 합성 진폭이 각각 `2A, √2A, 0, 2A`인지 확인 |
| 경로 샘플링·전환 | 같은 시각의 경로 끝값과 `P`의 성분 변위가 같고, 전환 전후 실제 거리와 위상이 유지되는지 확인 |
| 시계·일시정지 | 세 화면이 같은 시각을 사용하며 일시정지 후 위상이 누적되지 않는지 확인 |
| 간섭무늬 표시 | 마루가 지나가도 고정점의 진폭 무늬는 유지되고, 순간 변위만 바뀌는지 확인 |
| 점·막대 축척 | 두 성분이 같은 방향으로 최대 변위일 때 합성 표시가 같은 축척에서 두 배가 되는지 확인 |

수식과 화면을 함께 바꾸었다면 관련 수치 사례와 해당 화면을 확인한다. 물리 관계나 사용자 동작을 확인하는 최소한의 검증을 선택하고, 완료 보고에는 실제 확인한 범위만 짧게 적는다.
