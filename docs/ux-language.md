# 학생 화면과 언어

## 1. 화면을 설계하는 기준

- 조작할 대상과 조작 결과를 가까이 둔다. 이동할 수 있는 점에는 손잡이와 선택 표시를 제공한다.
- 처음부터 움직이는 파동과 선택할 수 있는 점을 보여 준다. 첫 조작은 손잡이와 선택 표시로 유도하고, 필요한 안내는 짧게 곁들인다.
- 기본 화면에는 지금 필요한 조작과 값만 둔다. 보충 설명은 해당 용어나 조작에 가까운 도움말로 제공한다.
- 파원, 경로, 끝점, 비교부의 성분은 같은 색과 식별 표시를 유지한다.
- 모든 표시가 같은 순간을 보여 준다. 사용자가 일시 정지하지 않으면 경로를 펼치거나 관측점을 바꿀 때도 진동이 이어진다.
- 학생 화면의 설명은 학습할 현상과 현재 조작에 한정한다. 구현 구조, 계산 방식, 개발 진행 상태는 개발 문서와 개발 전용 도구에서 관리한다.

## 2. 공간에서 경로 비교로 이어지는 동작

### 관측점 선택

- 두 파원과 관측점 `P`가 어느 위치에 있는지 구별할 수 있게 표시한다.
- 관측점은 화면을 누르거나 기존 점을 움직여 선택할 수 있다. 선택한 위치에 두 경로가 연결된다.
- 파원과 관측점의 손잡이는 서로 구별한다. 손잡이의 실제 터치 영역은 보이는 점보다 넓게 확보한다.
- 손잡이 둘레의 점선 포커스 표시는 Tab·방향키 조작 때만 나타낸다. 마우스·터치·펜 조작에서는 숨기되 키보드로 이어서 조작할 수 있도록 포커스 자체는 유지한다.
- P는 파원 1·2와 동일한 반지름 12px·테두리 2.5px의 원을 공유하고, 중앙의 작은 측정점으로 정확한 위치를 표시한다. P의 테두리는 흰색이며 내부는 파원과 같은 어두운 색을 불투명도 30%로 채워 파동이 비치도록 한다. `P`는 수식의 점 표기처럼 가벼운 세리프 이탤릭과 가는 어두운 대비선으로 오른쪽에 두고, 오른쪽 가장자리에서는 왼쪽으로 옮긴다. 터치 영역은 지름 48px를 유지한다.
- 경로 비교를 열어도 공간 속 관측점과 두 경로의 관계를 확인할 수 있게 유지한다.
- 기본 배치의 관찰 창은 기존 크기와 최소 높이를 유지하고, 같은 거리 축척으로 창 가장자리까지 파동을 그린다. P의 이동 범위는 현재 축척에서 화면과 경로 비교에 들어가는 만큼 확장한다. 손잡이 가장자리 여백은 16px이며, 펼친 경로와 진동 막대 사이에도 최소 16px를 남긴다. 파원 간격을 바꿔도 P가 밀려나지 않도록 최대 파원 간격을 기준으로 정한다. 파원의 이동 범위는 유지한다. 창을 납작하게 만들거나 별도 스크롤·탭을 추가하지 않는다.
- 가로 화면에서는 비교를 완전히 펼쳤을 때의 관찰 창을 기준으로 P의 범위를 정한다. 따라서 비교를 열고 닫아도 P의 물리 위치와 파장의 화면 크기는 바뀌지 않는다. 위아래의 남는 공간을 활용하고 경로가 너무 길어지는 모서리만 곡선으로 제한한다. 화면 회전·크기 변경 시 기존 위치가 새 범위를 벗어나면 가장 가까운 허용 위치로 옮긴다.
- 바깥 표시 영역을 누르거나 P를 범위 밖으로 끌면 이동 가능한 경계와 `P는 점선 테두리 안에서 움직여요.`를 잠깐 표시한다.
- 경계는 1px의 옅은 짧은 점선으로 0.26초에 걸쳐 드러낸다. 안내는 반투명한 어두운 바탕에 작게 표시하고, 0.07초 뒤부터 3px 올라오며 나타난다. 입력이 멈추면 경계와 안내는 약 0.4초 동안 서서히 사라진다. 동작 감소 설정에서는 즉시 전환한다.

### 파원 목표 지정과 전파

- 실제 파원 손잡이와 목표 위치를 구별한다. 드래그 중에는 큰 점선 원 두 개로 목표 간격을 미리 보여 주며 실제 파원은 이전의 진동·이동을 계속한다.
- 파원 중심 사이가 화면에서 32px보다 가까워지면 왼쪽에 공통 `간격 ↕` 손잡이를 표시한다. 위로 끌면 간격을 넓히고 아래로 끌면 좁힌다. 기존 파원 손잡이·슬라이더·방향키 입력도 유지하며, 공통 손잡이 역시 미리보기 후 놓을 때 확정한다.
- 손을 떼면 목표를 확정한다. 실제 파원은 파동보다 느리게 이동하고 목표에서 멈춘다. 다시 끌 때도 이전 목표 이동을 계속하다가 놓는 순간 새 목표를 받는다.
- Escape·포인터 취소·캡처 상실은 미확정 미리보기를 버린다. 간격 슬라이더는 입력 중 미리보기, 변경 확정 시 목표 지정이다. 방향키는 한 번씩 목표를 확정한다.
- 조절기에 표시하는 간격은 목표값이다. 이동 중 점선 원과 `파원이 점선 위치로 이동하고 있어요.`로 의미를 연결한다.
- 정지 중 확정한 목표는 `재생하면 점선 위치로 이동해요.`로 안내한다. 재생 여부를 자동으로 변경하지 않는다.
- 파장 설정은 파원에서 새로 발생하는 파동에 적용한다. 기존 공간의 파형은 재작성하지 않는다.
- 이동 뒤 공간에 남는 작은 속빈점은 P에 지금 도착하는 파동의 과거 출발 위치다. 같은 거리 보조점과 혼동하지 않도록 이동의 영향이 남은 동안 같은 거리 보조점은 숨긴다.
- 경로의 시작점은 이 출발 위치이고, 그 선분에서 현재 시각의 변위를 샘플링한다. 시작점 번호를 유지하되 과거 위치면 속빈 표시를 사용한다. 곡선은 물 입자나 파면의 이동 궤적이 아니다.

### 두 경로 펼치기

- 상세 옵션의 `경로에 파형 표시` 토글로 접힌 상태에서도 두 공간 경로의 순간 파형을 표시한다. 기본은 켜짐이며 펼친 비교에서는 항상 파형을 표시한다. 접으면 토글의 선택 상태로 돌아온다.
- 실제 두 경로가 회전하고 펴져 나란히 놓이는 과정을 연속적으로 보여 준다.
- 펼치기는 1.4초, 접기는 1.1초로 처음과 끝에서 부드럽게 가감속한다. 비교 영역의 높이도 같은 진행도로 확장·축소한다. 같은 거리 연결선·보조점·눈금·오른쪽 진동 표시는 도착한 뒤 0.32초 동안 서서히 나타난다. 접을 때는 먼저 0.18초 동안 사라진 뒤 파형이 돌아간다. 동작 감소 설정에서는 모두 즉시 전환한다.
- 펼쳐진 두 경로는 **시작점을 정렬**한다. 공간의 원래 경로와 펼친 경로는 화면에서도 길이와 파장 크기가 같다. 이 동일성은 펼치는 동안에도 유지한다.
- 가로 공간은 공통 축척으로 표현한 두 경로의 길이에 맞춰 확보한다. 두 도착점의 위치 차이가 실제 경로차에 비례하도록 배치한다.
- 더 긴 경로가 어느 쪽인지에 관계없이 행 순서는 `파원 1`, `파원 2`로 고정하고 파원의 색도 유지한다.
- 짧은 경로 끝과 다른 경로의 같은 거리를 잇는 수직 보조선은 기존처럼 순간 변위를 따라 움직인다. 긴 경로 끝에도 같은 형태의 막대를 두어 다른 행의 수평 끝값 연결선과 잇는다. 파형을 실제 경로 바깥으로 연장하지 않는다.
- 같은 거리를 표시하는 보조점은 속을 비워 실제 도착점과 구별한다. 보조점의 이름과 표시는 두 경로에서 같은 거리를 짚는 역할에 맞춘다.
- 두 경로가 같은 길이여도 양 끝을 연결하는 막대와 전체 눈금자는 표시한다. 경로차가 없으면 음영·추가 막대·속빈 보조점을 숨겨 중복을 피한다.
- 중앙 눈금자는 짧은 경로 끝을 0으로 삼아 오른쪽 파원 1·2 진동 표시 열까지 이어진다. 두 행의 평형선 사이 중앙 높이에 고정해 진동에 따라 위아래로 흔들리지 않게 한다. P 이동으로 경로 길이가 바뀌면 눈금의 가로 기준점도 짧은 경로 끝을 따른다. 이 기준점부터 λ 간격의 긴 눈금과 λ/2 위치의 짧은 보조 눈금을 사용하며, 아래 한 파장 기준 막대도 같은 모양을 쓴다. 파장을 바꾸면 새 조건이 공간에 도달한 뒤 새 간격으로 표시한다.
- 두 연결 막대 사이의 경로차 구간만 중앙 눈금자의 8px 높이 띠 안에서 더 진한 음영으로 강조한다. 아래 한 파장 눈금과 같은 공통 요소를 사용해 선 두께와 눈금 모양을 통일한다. 음영은 파형을 덮지 않고, 어느 경로가 길어도 동일한 규칙을 적용한다.
- 펼치는 동작 중에도 공통 시계의 시간을 그대로 사용해 모든 진동을 이어 간다. 재생 여부는 사용자의 재생·일시 정지 조작으로 결정한다.

위의 같은 거리·추가 길이·한 파장 비교는 표시 중인 프레임이 정상 상태일 때 제공한다. 두 보기에서 변화가 퍼지는 동안에는 해당 보조 표시와 `경로차/λ`를 유보하고 `각 위치의 현재 파형`을 표시한다. `즉시 최종 상태`에서는 비교와 눈금을 즉시 갱신한다. 출발점 정렬·실제 선분 길이·끝값과 P의 대응은 항상 유지한다.

### 오른쪽의 세 진동

- 각 경로의 끝점에서 **수평 직선 점선**으로 오른쪽 표시점까지 연결한다.
- `파원 1`, `파원 2`의 진동 막대는 위아래 같은 열에 배치하고, `두 파의 합`은 그 오른쪽 중간 높이에 둔다. 합 전용 파형 행과 긴 가로선은 두지 않으며, 비교 영역 높이는 210px로 줄인다.
- 각 진동 막대는 자기의 짧은 0선을 가지며, 세 막대 모두 동일한 변위 축척을 사용한다. 합에는 최대 합성 진폭까지 움직일 공간을 확보한다.
- 두 성분의 표시점은 해당 경로 끝점과 같은 높이에서 동시에 움직인다. 합의 표시점은 같은 순간 두 변위를 더한 값을 보여 준다.
- 비교부 전체의 제목은 `P에서의 진동`처럼 사용한다. 세 막대는 **같은 관측점 P의 두 기여와 그 합**이다.
- 관측점 이름은 공통인 `P`로 유지하고, 각 표시는 파원의 기여와 합을 나타내는 이름으로 구별한다.
- 필요하면 0선에서 각 점까지 변위 막대를 표시한다. 막대의 위·아래 방향과 길이로 부호와 크기를 읽게 한다.
- 각 점의 움직임이나 짧은 잔상으로 진동 방향을 구별할 수 있게 한다. 위상 관계는 점의 높이와 움직이는 방향을 함께 보고 읽을 수 있게 표현한다.
- 보조선은 끝점의 값을 대응시키는 수평 직선 점선으로만 표현한다. 파형은 실제 경로 안에서 끝내고, 보조선 구간은 두 점의 높이를 연결하는 역할만 맡긴다.
- 오른쪽 합성점과 변위 막대는 P에서의 합성 변위를 나타낸다. 이 비교부의 결과는 한 관측점 P에서의 진동이다.

## 3. 상태별 최소 표현

### 파동 색상 선택

- 경로 펼치기 버튼 옆 색상바와 화살표를 누르면 색상 미리보기·이름·현재 선택 표시가 있는 목록을 연다. 선택, 바깥 누르기, Escape로 닫는다. 키보드로 열고 방향키 또는 Tab으로 선택 항목에 도달할 수 있다.
- 기본 `간섭 대비`는 음의 변위를 하늘색(`#7EBFE2`), 양의 변위를 살구 코랄(`#F0A690`), 0을 짙은 먹색(`#141D25`)으로 표시한다. 양끝의 상대 휘도를 비슷하게 맞춰 같은 크기의 양·음 변위가 한쪽만 더 강해 보이지 않도록 한다. `푸른 물결`과 `은빛 물결`은 음의 변위를 어둡게, 0을 중간 밝기로, 양의 변위를 밝게 표시한다. 실제 수면의 조명·굴절을 계산하는 표현은 아니다.
- 두 물결 프리셋은 정규화된 변위 v를 v + 0.2v(1−v²)로 변환해 0 근처의 명암 대비를 완만하게 높인다. 세 색상 사이에는 단조 3차 보간을 적용하고 0 양쪽의 접선 기울기를 일치시켜 색 변화가 꺾이지 않게 한다. 음·양의 밝기 순서와 세 기준색은 유지하며 변위 0을 별도의 검은 선으로 표시하지 않는다.
- `간섭무늬`에서는 부호 없는 도착 위상 포락선(정상 상태에서 합성 진폭) 0→최대를 어두움→밝음으로 표시하며, 범례와 미리보기도 현재 표시 물리량에 맞춘다. 두 물결 프리셋은 같은 완만한 대비 곡선으로 작은 진폭의 명암 차이를 조금 높이고, 최저·최고 색상 사이를 연속적으로 표시한다.
- `상세 옵션`의 변화 방식은 두 보기에 공통으로 적용한다. `파동 변화 과정 생략`을 끄면(기본값) 발생 이력을 유지하고, 이 토글을 켜면 켜는 시점과 파장·파원 위치 확정 시 현재 시각·발생 위상을 보존한 채 최종 상태로 정착시킨다. 미확정 위치는 별도 정상 상태 프레임으로 미리 보고 취소할 수 있다. 보기 전환과 초기화는 선택한 옵션을 유지하며, 보기 전환 자체는 엔진을 정착시키지 않는다.
- 상세 옵션에 `파동 변화 과정 생략` 토글과 경로에 파형 표시 토글을 모은다. 기본값은 생략 꺼짐, 파형 표시 켜짐이다. 각 설명 버튼은 마우스 올림·키보드 포커스·터치 누르기로 버블을 연다. 옵션은 실험 초기화에도 유지한다.
- 색상 선택은 재생·정지, 파원 조건, 비교부의 식별 색상을 바꾸지 않는다. 실험을 초기화해도 선택한 색상은 유지한다. 새로 페이지를 열면 기본 색상으로 시작한다.

### 관찰 상태

| 상태 | 화면에서 보여 줄 것 | 필요한 경우에만 쓰는 짧은 문구 |
| --- | --- | --- |
| 기본 장면 | 움직이는 파동, 선택할 수 있는 관측점, 재생 상태 | `관측할 곳을 눌러 보세요.` |
| 관측점 선택·이동 | P 표시, 두 경로, 선택된 점의 손잡이 | `경로 펼치기` |
| 경로 비교 | 시작점 정렬, 같은 거리 표시, 추가 길이, 두 성분과 오른쪽 합성 진동 | `경로차`, `P에서의 진동` |
| 일시 정지 | 모든 파동과 비교점이 같은 순간에 정지 | 버튼 이름 `재생` |
| 재생 중 | 모든 파동과 비교점이 계속 진동 | 버튼 이름 `일시 정지` |
| 두 경로의 길이가 같음 | 같은 위치에서 끝나는 두 경로, 추가 길이 없음 | `경로차 0` |
| 두 파가 완전히 상쇄되는 조건 | 성분점은 진동하고 합의 점은 0에 머묾 | `두 파의 합은 진동하지 않아요.` |
| 파원 드래그 미리보기 | 실제 파원과 분리된 점선 목표 원 | `손을 떼면 점선 위치로 이동해요.` |
| 파장·위치의 영향이 P에 전달 중 | 두 성분과 합의 실제 순간 변위 | `새 조건이 P에 도착하는 중` |
| 조건 변경 | 선택한 변화 방식에 따라 전파 또는 최종 상태 표시 | 상세 옵션 설명 버블에서 차이 안내 |

- 첫 조작 안내는 해당 조작을 마치면 접고, 이후에는 손잡이·선택 표시·즉각적인 화면 반응으로 조작을 안내한다.
- 상쇄 간섭 표시는 두 파의 위상 관계와 합성 진폭을 기준으로 결정한다. 한 순간의 합성 변위가 0인 상태와 구별한다.
- 두 보기 모두 변화 중에는 정상 상태 합성 진폭·보강·상쇄 판정을 유보한다. 색상바 위에는 파동 보기에서 `− 0 +`, 간섭무늬에서 `0 최대`만 표시한다. 전체 물리량 설명은 접근성 이름으로 유지하며, 변화 중임은 필드 상태 안내로 표시한다.
- 숫자를 제공할 때는 해당 길이·막대·조절기 가까이에 단위와 함께 표시한다.
- `경로차 0.5λ`와 같은 표시는 필요할 때 `파장의 절반`이라는 짧은 풀이를 함께 볼 수 있게 한다.

## 4. 학생에게 쓰는 말

### 공통 원칙

- 중고등학생이 한 번에 읽을 수 있는 짧은 문장을 쓴다. 한 문장에는 한 행동이나 한 관계를 담는다.
- 조작 이름은 `경로 펼치기`, `파장`, `일시 정지`처럼 대상과 행동을 바로 알 수 있게 쓴다.
- 설명이 필요할 때는 `점을 움직여 보세요.`처럼 자연스러운 말투로 필요한 행동과 관계를 바로 전한다.
- 한국 교육과정에서 쓰는 정확한 과학 용어를 명칭으로 사용하고, 쉬운 풀이를 덧붙인다. 비유는 용어의 뜻을 보충하는 설명으로 사용한다.
- `분석 파이프라인`, `렌더러`, `상태 동기화`, `모듈`, `캐시`, `성능 최적화`, `MVP` 등 구현 관련 용어와 개발 원칙·설계 의도는 개발 문서와 개발 전용 도구에서만 다룬다. 학생 화면에는 현상과 조작을 이해하는 데 필요한 내용만 쓴다.

### 사용할 용어와 범위

| 용어 | 학생에게 필요한 풀이·사용 범위 |
| --- | --- |
| 파원 | 파동이 시작되는 곳. 화면 이름은 `파원 1`, `파원 2`. |
| 관측점 | 진동을 살펴보는 위치. 화면에는 `P`와 함께 표시한다. |
| 파장 | 정지한 파원이 한 주기 동안 내보내는 파동의 공간 간격. 조절값은 파원에서 새로 만드는 파동의 설정이며, 변화 중 전체 화면의 간격과 같다고 설명하지 않는다. |
| 진동수 | 1초 동안 진동하는 횟수. 파동의 진행 속력과 구별한다. |
| 주기 | 한 번 진동하는 데 걸리는 시간. |
| 진폭 | 평형 위치에서 가장 멀리 벗어나는 거리. 순간 변위와 구별한다. |
| 변위 | 평형 위치에서 어느 방향으로 얼마나 벗어났는지 나타내는 양. 막대의 방향과 길이로 보여 준다. |
| 위상·위상차 | 한 주기에서 진동이 어느 단계에 있는지, 두 진동 사이에 그 단계가 얼마나 다른지 나타낸다. |
| 경로차 | 두 파원에서 같은 관측점까지 이어지는 두 경로 길이의 차. 추가 길이와 연결한다. |
| 중첩 | 같은 위치에서 각 파에 의한 변위를 더하는 관계. 더하는 양은 각 파의 순간 변위다. |
| 간섭 | 파들이 겹쳐 진동이 커지거나 작아지는 현상. |
| 보강 간섭 | 두 파가 같은 위상으로 만나 합성 진폭이 가장 커지는 조건을 설명할 때 쓴다. |
| 상쇄 간섭 | 두 파가 반대 위상으로 만나 합성 진폭이 가장 작아지는 조건을 설명할 때 쓴다. 완전히 0이 되는지는 진폭 조건도 확인한다. |
| 마디·배 | 마디는 진폭이 0인 위치, 배는 진폭이 최대인 위치. 두 파원의 간섭에서는 필요할 때 `마디선`, `배선`으로 표시한다. 순간 변위가 0인 위치와 마디를 구별한다. |

- 표시점의 세로 위치는 순간 **변위**다. 점이나 숫자의 제목은 `변위`, `두 파의 합`처럼 실제로 표시하는 양과 대상에 맞춘다.
- 합성 진폭이 0이면 위상이 정의되지 않는다. 이 상태는 `두 파의 합은 진동하지 않아요.`처럼 진동 여부로 표현한다.
- `진폭이 작다`는 진동 범위, `변위가 0이다`는 현재 위치, `반대 위상이다`는 두 진동의 관계를 설명할 때 각각 사용한다.
- 파형은 각 위치의 순간 변위를 나타내는 곡선으로 설명한다. 물 입자의 이동 경로와 구별한다.

## 5. 좁은 화면과 다양한 조작 방식

- 너비 560px 이상·높이 500px 이하인 가로 화면에서는 관찰 창을 왼쪽, 경로 비교를 오른쪽에 배치한다. 비교부는 180px 높이로 행 간 여백을 줄이되 변위 축척은 유지한다. 비교 열기 전에도 비교부 폭으로 거리 축척을 예약하며, 열 때 관찰 창의 가로 폭만 부드럽게 줄여 공간을 내준다. 닫으면 관찰 창이 전체 폭으로 돌아온다.
- 가로 화면의 재생·보기 버튼은 위 한 줄, 슬라이더는 아래 한 줄로 모은다. 중복 거리 읽기는 숨기되 공간과 비교부의 거리 표시는 유지한다. 이동 안내는 조절줄 오른쪽에서 기존 상태 문구를 대신해 높이를 늘리지 않는다. 도움말은 화면 아래에서 열 수 있다.
- 작은 세로 화면의 조절부는 관찰 영역에 겹치는 하단 고정을 사용하지 않는다. 여백을 줄이고 원래 문서 흐름에 배치한다. 극단적으로 짧은 세로 화면에서는 전체 내용이 화면 높이를 넘을 수 있으나 파형을 덮거나 손잡이를 축소하지 않는다.
- 화면 폭이 줄어도 두 경로의 시작점 정렬을 유지한다. 크기를 조정할 때는 공간과 비교 화면에 같은 거리 배율을 적용한다. 현재 P 위치에 맞춘 비교만의 자동 확대 대신 조작부 배치와 화면 높이를 조정한다.
- 좁은 화면에서도 두 성분과 오른쪽 합성점 배치 및 공통 변위 축척을 유지한다. 합성점 공간을 포함해 거리 축척을 계산하고 공간·비교 화면에 함께 적용한다.
- 좁은 화면에서도 시작점을 정렬하고, 값의 대응은 수평 직선 점선 또는 동일한 식별 표시와 동시 움직임으로 표현한다.
- 손잡이의 조작 영역과 글자의 가독성을 우선 확보한다. 공간이 부족하면 부가 값과 도움말을 먼저 접는다.
- 드래그 외에 눌러 위치 선택, 키보드 이동 등 같은 결과를 얻는 조작을 제공한다.
- 키보드 초점은 보이고, 조절기에는 이름과 현재 값을 제공한다. 화면 읽기 도구에는 조작에 따른 상태 변화를 알리고, 빠르게 진동하는 변위의 읽기는 사용자가 값을 확인할 때 제공한다.
- 파원과 합은 색 외에도 `1`, `2`, `합` 표시나 모양으로 구별한다. 같은 거리의 속빈점도 실제 끝점과 구별한다.
- 일시 정지는 항상 쉽게 찾을 수 있어야 한다. 동작 감소 설정에서는 펼치는 전환을 간소화할 수 있지만, 재생 여부는 사용자가 정한다.

## 6. UX 구현의 완료 기준

- 관측점의 손잡이와 선택 표시만으로 점을 선택하고 움직일 수 있다.
- 경로 비교를 열면 두 시작점, 같은 거리, 추가 길이를 바로 찾을 수 있다.
- 두 경로 끝점과 오른쪽 성분점의 대응이 수평선 또는 일관된 식별 표시로 드러난다.
- 두 성분과 합이 같은 P를 나타내며, 독립된 0선과 같은 변위 축척으로 읽힌다.
- 재생·일시 정지가 모든 표현에 함께 적용되고, 화면 전환 중에도 사용자가 선택한 재생 상태가 유지된다.
- 학생 화면은 현상과 조작에 필요한 내용으로 구성되고, 실제 보이는 값과 문구의 과학적 의미가 일치한다.

완료 기준은 변경한 UI와 그 변경이 직접 영향을 주는 동작에 한해 확인한다. 문구·정렬 변경은 해당 문구와 배치를 중심으로 확인한다.

### 관찰 도구 배치

경로 비교·색상 선택·상세 옵션을 상단의 한 조작 그룹에 둔다. 버튼 높이와 선형 SVG 아이콘을 통일한다. 핵심인 경로 펼치기는 진한 글자와 파원 1·2 색을 재사용한 두 선 아이콘으로 구분한다. 경로 버튼에만 옅은 청록 배경을 사용하고, 펼친 상태에서는 배경을 더 진하게 표시한다. 모서리는 작게 둥글리고 테두리·그림자·밑줄은 두지 않는다. 색상 선택과 상세 옵션은 배경 없이 유지한다. 펼치기 버튼은 `경로 펼치기 / 경로 접기`로 동작을 알리고, 펼치기에는 두 선이 평행한 아이콘을, 접기에는 두 선이 안쪽으로 기울어진 아이콘을 쓴다. 긴 문구의 폭을 보이지 않는 글자 영역으로 예약해 펼치기·접기 전환 때 버튼·아이콘·주변 버튼 위치가 변하지 않게 한다. 동작 감소 설정에서는 아이콘 전환을 즉시 적용한다. 드롭다운 화살표는 색상 선택에만 사용한다. 색상바 아래 별도 도구 줄은 두지 않는다. 작은 세로 화면은 보기 선택과 도구 그룹을 두 줄로, 짧은 가로 화면은 한 줄과 아이콘형 옵션 버튼으로 배치한다. 열리는 패널은 화면 안으로 제한하고 재생·정지 조작과 겹치지 않도록 기본 조작 배치를 검증한다.

### P의 선 통과 걸림

시각적 힌트 없이, 정상 상태에서 P를 드래그해 마디선·보강선을 실제로 통과할 때만 정확한 선 위에서 짧게 걸린다. 선 통과 직후 4px 이내에서만 걸림을 시작한다. 걸린 뒤에는 선을 가로지르는 방향으로 6px까지 유지하며 선을 따라서는 이동할 수 있다. 이후 3px 구간에서 부드럽게 포인터 위치로 복귀하며, 9px부터 완전히 풀린다. 풀린 뒤 같은 선에서 12px 이상 벗어나기 전에는 다시 걸리지 않는다. 복귀는 입력 위치에 따라 계산하므로 도중에 손을 떼면 보이는 위치에 그대로 멈춘다. 큰 이동으로 선을 지나친 경우에는 되돌려 붙이지 않는다. 근처 클릭·터치, 접근만 한 경우, 키보드 이동, 손을 떼는 순간에는 위치를 보정하지 않는다. 따라서 걸림을 넘긴 뒤 되돌리거나 새로 누르면 선 바로 옆에도 놓을 수 있다.

과도 상태·파원 미리보기에서는 적용하지 않는다. 조건·축척 변경이나 입력 종료·취소 시 걸림 상태를 버린다. 허용 영역 밖이나 위상장이 평평한 구간에서는 자유 입력을 우선한다.

### 관찰 도움말의 범위

P에서 진동의 크기 찾기 → 펼친 경로의 경로차와 간섭 조건 비교 → 순간 변위 0과 지속적인 상쇄 구별 → 파장·간격 변경에 따른 무늬 탐구로 구성한다. 정상 상태의 등진폭·동위상 조건과 λ의 뜻을 함께 설명한다. 옵션별 동작, 미리보기·확정 과정, 내부 표시 사정은 반복하지 않고 해당 옵션 툴팁에 맡긴다. 키보드로 점을 선택하고 이동하는 안내는 한 줄로 유지한다.
