# 학생 화면과 언어

이 문서는 현재 화면·입력·표현 규격을 관리한다. 계산 정의는 [물리 모델](physics-model.md), 코드 경계는 [구조와 재사용](architecture.md), 수업 목표와 후보 기능은 [제품 설계](product-design.md)를 따른다.

## 1. 기본 조작과 선택 상태

| 조작 | 동작·기본값 |
| --- | --- |
| 파동 모습 / 간섭무늬 | 기본은 파동 모습. 순간 변위 / 도착 위상 포락선을 표시한다. 정상 상태의 포락선은 합성 진폭이다. |
| 경로 펼치기 / 경로 접기 | 기본은 접힘. 공간의 두 경로를 시작점이 정렬된 두 행으로 펼친다. |
| 파동 변화 과정 생략 | 상세 옵션, 기본 꺼짐. 켜면 파장·간격 변경의 중간 과정을 생략하고 최종 상태를 표시한다. |
| 경로에 파형 표시 | 상세 옵션, 기본 켜짐. 접힌 공간 경로에도 파형을 표시한다. 펼친 경로의 파형은 항상 보인다. |
| 색상바 | 경로 버튼 옆에서 푸른 물결·간섭 대비·은빛 물결 순서로 선택. 기본은 푸른 물결. |
| 일시 정지 / 재생 | 전파·파원 이동·모든 진동을 함께 정지/재개한다. |
| 재생 속도 | 상세 옵션의 단계식 슬라이더. 0.25×·0.5×·1×·1.5×·2×, 기본 1×. 전파·파원 이동·진동의 시간 진행을 함께 조절한다. 일시 정지와 처음으로 조작 후에도 선택을 유지한다. |
| 처음으로 | 초기 물리 조건·시간·P를 복원하고 재생·보기·옵션·색상 선택은 유지한다. 새 페이지는 기본값으로 시작한다. |

파장과 파원 간격의 초기값·범위는 `model/state.ts`가 소유하고, 화면 수치는 cm로 표시한다. 현재 초기 조건은 제품 문서에서 확인한다.

파원 드래그는 목표 미리보기 → 놓기 확정이다. 기본 전파 방식에서는 실제 파원을 유지하고 점선 목표 원을 움직인다. 확정 후 파원이 목표로 이동한다. 생략 옵션에서는 미확정 위치의 최종해를 미리 보여 준다. Escape·포인터 취소·캡처 상실은 미리보기를 버린다. 슬라이더도 입력 중 미리보기, 변경 완료 시 확정한다. 방향키는 목표를 한 단계씩 확정한다.

## 2. P와 파원 손잡이

- 파원 1·2는 원과 번호, P는 같은 크기의 원과 중앙 측정점으로 표시한다. 원 반지름 12px, 테두리 2.5px, 선택 반경 24px다. P 내부는 어두운 색을 불투명도 30%로 채우며 흰 테두리와 반지름 1.8px의 중앙점을 쓴다. 이탤릭 `P`를 바깥에 두고 오른쪽 끝에서는 왼쪽으로 옮긴다.
- 마우스·터치·펜 조작에는 초점 점선을 표시하지 않는다. Tab·방향키에서는 초점을 보이며, 방향키 이동과 Shift를 통한 큰 이동을 제공한다.
- 교사 모드에서도 파원 원과 숫자는 공통 비율을 유지한다. 공간 경로가 같은 파원 위에 놓이면 번호 원은 하나만 보이며 손잡이 조작은 유지한다. 펼친 경로에서도 같은 표시를 사용하고, 장면을 옮겨도 원·숫자·테두리의 크기를 유지한다.
- 파원 중심 간 거리가 32px보다 작으면 왼쪽 40px 위치에 공통 `간격 ↕` 손잡이를 표시한다. 위로 끌면 넓어지고 아래로 끌면 좁아진다. 겹치는 선택 영역은 가장 가까운 중심으로 판정한다.
- P는 화면을 누르거나 끌어 이동한다. 허용 영역은 최종 펼침 카메라에서 손잡이 여백 16px를 확보한 범위와 비교 가능한 최대 경로 길이의 교집합이다. 파원 최대 간격을 기준으로 하므로 간격 변경이나 비교 열기·닫기로 P가 밀리지 않는다. 화면 크기가 바뀌어 범위를 벗어나면 가장 가까운 허용점으로 옮긴다.
- 범위 밖 입력에는 얇은 1px 점선과 `P는 점선 테두리 안에서 움직여요.`를 잠깐 표시한다. 점선은 불투명도 .45로 260ms에 걸쳐 나타나고 420ms에 걸쳐 사라진다. 안내는 70ms 뒤 3px 올라오며 나타나고 약 360ms에 사라진다. 입력 후 1400ms에 숨김을 시작한다. 동작 감소 설정에서는 전환을 생략한다.

### 선을 통과할 때의 걸림

일반 탐색과 교사 수업의 관찰·설명·자유 조작은 같은 걸림을 사용한다. 교사 수업의 두 예측 정책에서는 걸림을 끄며, 예측에서 잠시 자유 조작으로 나가면 켜고 수업으로 돌아오면 다시 끈다.

시각적 힌트 없이 정상 상태에서 드래그로 마디선·보강선을 실제 통과할 때만 걸린다. 통과 직후 5px 이내에서 잡고, 선의 수직 방향으로 8px까지 유지한다. 이후 4px 구간에서 포인터로 부드럽게 복귀하며 12px부터 풀린다. 풀린 선에서 16px 넘게 벗어나야 다시 잡힌다. 선을 따라서는 자유롭게 움직인다.

큰 이동·근처 누름·접근만 한 경우·키보드·손을 떼는 순간에는 보정하지 않는다. 따라서 선 옆에도 놓을 수 있다. 과도 상태·파원 미리보기·허용 영역 밖·평평한 위상장에는 적용하지 않으며 조건·축척·입력 세션 변경 시 걸림 상태를 버린다.

## 3. 경로 펼치기와 진동 비교

- 공간의 두 선분과 펼친 경로는 **공통 거리 축척(px/m)**을 사용한다. 길이와 한 파장의 화면 크기를 보존한 채 회전·이동하며 출발점을 정렬한다. P·파장·파원 간격 변경으로 축척을 바꾸지 않는다.
- 파원 1·2의 행 순서와 색은 경로 길이에 관계없이 고정한다. 이동 영향이 남아 있으면 P에 도착한 성분의 과거 발생 위치에서 시작한다. 과거 위치는 작은 속빈점이며 현재 파원·목표와 구별한다.
- 펼치기는 1400ms, 접기는 1100ms로 가감속한다. 비교 영역도 같은 진행도로 확장·축소한다. 도착 후 보조 표시를 320ms에 걸쳐 드러내고, 접을 때는 먼저 180ms에 걸쳐 숨긴다. 화면 전환은 물리 시계와 독립적이고 동작 감소 설정에서는 즉시 완료한다.
- 경로 끝값을 수평 점선으로 각 성분점에 연결한다. 두 성분은 각 행의 오른쪽 같은 열에, 합성점은 그 오른쪽 중간 높이에 둔다. 합 전용 파형 행은 없다. 세 점은 같은 P의 순간 변위와 합을 나타내며, 두 경로와 동일한 변위 축척·각자의 짧은 0선을 쓴다.
- 정상 상태에서 짧은 경로 끝과 긴 경로의 같은 거리 지점을 수직 막대로 잇는다. 긴 경로 끝에도 다른 행의 수평 끝값 연결선까지 잇는 막대를 둔다. 짧은 파형을 실제 경로 밖으로 연장하지 않는다.
- 중앙 눈금자는 **짧은 경로 끝을 0**으로 시작해 파원 1·2의 진동 표시 열까지 이어진다. 두 행의 평형선 사이 중앙에 고정한다. λ 긴 눈금과 λ/2 짧은 눈금을 사용하고, 아래 한 파장 기준 막대도 같은 요소를 쓴다.
- 두 눈금자에는 옅은 점선 사인파를 겹친다. 눈금자 시작을 기준으로 한 주기의 가로 길이가 정확히 λ이며, 반 파장 눈금은 반 주기에 대응한다. 세로 높이는 읽기 위한 고정 크기로 실제 진폭을 나타내지 않는다. 기준 파형은 재생 중에도 움직이지 않고, 파장·눈금자 위치·화면 축척만 따른다. 일반 탐색과 교사 수업은 공통 눈금자를 재사용하며 기존 공개 시점과 변화 중 유보를 유지한다.
- 경로차는 두 막대 사이의 8px 높이 눈금 띠 안에서만 음영으로 강조한다. 파형 위에는 음영을 두지 않는다. 경로차가 0이면 추가 막대·음영·속빈점을 숨기되 두 끝점 연결과 눈금은 유지한다.
- 변화 중에는 순간 변위·도착 거리와 끝값 대응을 계속 표시한다. 공간 전체가 정상 상태가 될 때까지 같은 거리 보조점·막대·파장 눈금·경로차/λ 해석을 유보하고 `각 위치의 현재 파형`을 표시한다.

## 4. 색상과 도구 디자인

`간섭 대비`는 음의 변위에 하늘색, 0에 먹색, 양의 변위에 살구 코랄을 사용한다. 양끝 밝기를 비슷하게 맞춘다. 두 물결 프리셋은 음의 변위가 어둡고 양의 변위가 밝으며, 0 근처의 대비를 약하게 높이고 기울기를 연속적으로 연결한다. 색상값·보간식은 `visual/field-palettes.ts`를 기준으로 하며 CPU·GPU·범례가 같은 표를 사용한다. 수면 조명·굴절을 계산하는 표현은 아니다.

간섭무늬는 부호 없는 값이므로 0에서 최대로 갈수록 밝게 표시한다. 색상바 위에는 파동 보기 `− 0 +`, 간섭무늬 `0 최대`만 두고 전체 의미는 접근성 이름으로 제공한다. 색상 변경은 물리 조건과 파원 식별 색에 영향을 주지 않는다.

경로 버튼·색상 선택·상세 옵션은 같은 높이의 도구 그룹이다. 경로 버튼에만 옅은 청록 배경을 사용하고 펼친 상태에서 더 진하게 한다. 모서리는 작게 둥글리며 테두리·그림자·밑줄은 없다. 펼치기 아이콘은 평행한 두 선, 접기 아이콘은 안쪽으로 기울어진 두 선이다. 긴 문구의 폭을 예약해 상태 변경으로 아이콘·주변 도구가 움직이지 않는다.

색상 선택과 상세 옵션은 배경 없이 표시한다. 드롭다운 화살표는 색상 선택에만 쓴다. 팝업은 화면 안에 배치하고 선택·바깥 누름·초점 이탈·Escape로 닫는다. 상세 옵션의 설명은 마우스 올림·초점·터치로 짧은 버블을 열며, Escape는 버블부터 닫는다. 색상 항목은 방향키·Home·End로도 이동할 수 있다.

## 5. 화면 크기와 접근성

- 기본 화면은 관찰 창·비교를 같은 열에, 데스크톱 조절기는 옆에, 작은 화면 조절기는 아래에 둔다. 비교 영역 높이는 기본 210px다.
- 너비 1100px·높이 600px 이상에서는 기존 배치를 유지하며 앱 너비를 창에서 좌우 16px를 뺀 값까지, 최대 1536px로 확장한다. FHD의 150%/125% 배율에 해당하는 CSS 너비 1280/1536px와 브라우저 도구 모음을 제외한 높이를 기준으로 한다. OS 권장 배율을 추측하거나 DPR로 앱을 다시 확대하지 않는다.
- 이 데스크톱 배치의 주요 조작 글자는 14–17px, 수치 출력은 18–22px다. 관찰 창은 높이 210–640px에서 남은 세로 공간을 사용하며, 펼친 비교 영역을 미리 예약해 열고 닫을 때 관찰 창과 축척이 바뀌지 않는다. 높이 600–659px에서는 글자 대신 여백을 줄인다. 모바일·낮은 가로 화면 배치는 그대로 유지한다.
- 너비 560px 이상·높이 500px 이하인 가로 화면은 필드 왼쪽/비교 오른쪽, 비교 높이 180px다. 비교를 열기 전부터 공통 축척을 예약하고, 열 때 필드 폭만 줄인다. 위에 보기·재생, 아래에 슬라이더를 모으며 중복 수치는 숨긴다. 도움말은 아래에서 연다.
- 작은 세로 화면에서는 보기 선택·관찰 도구를 두 줄로 둔다. 조절기를 파형 위에 고정하지 않는다. 극단적으로 짧은 세로 화면에서는 페이지가 길어질 수 있으나 파형·손잡이를 덮지 않는다. 추가 내부 스크롤로 공간을 해결하지 않는다.
- 화면 회전은 카메라·공통 축척을 재계산하고 진행 중 포인터 입력을 취소한다. 물리 조건·시각·재생 상태는 유지한다.
- 글자·손잡이를 먼저 줄이지 않고 부가 정보·여백을 조정한다. 색에 더해 번호·이름·행 순서를 사용한다. 키보드 초점과 조절기의 현재 값·단위를 제공하고, 확정 조작의 결과를 접근성 알림으로 전달한다.

## 6. 문구와 교육용 도움말

교사 수업의 별도 진행 규칙은 이 문서 마지막 절을 따른다.

학생 문구는 현상·행동·값의 의미를 설명한다. 엔진·캐시·상태 동기화 같은 구현 설명은 개발 문서에 둔다. 상시 설명은 줄이고 필요한 상세 내용은 해당 옵션 버블에 둔다.

| 용어 | 구별할 의미 |
| --- | --- |
| 파원 / 관측점 P | 파동이 시작되는 곳 / 진동을 살펴보는 위치 |
| 파장 | 새로 발생하는 파동의 설정값. 변화 중 전체 화면의 단일 간격으로 설명하지 않는다. |
| 진동수 / 주기 | 초당 진동 횟수 / 한 번 진동하는 시간. 파동 속력과 구별한다. |
| 변위 / 진폭 | 현재 방향·거리 / 평형 위치에서 최대 진동 거리 |
| 위상차 / 경로차 | 진동 단계 차이 / 같은 P까지 두 경로 길이 차이 |
| 중첩 | 같은 위치·시각의 두 순간 변위를 더함 |
| 보강 / 상쇄 | 같은 / 반대 위상에서 합성 진폭이 최대 / 최소인 조건. 완전 상쇄는 진폭 조건도 확인한다. |
| 마디 | 진폭이 0인 위치. 순간 변위가 0인 위치와 다르다. |

P의 정상/과도 판정은 엔진의 `probe.interference`를 따르며, 공간 전체 정상 여부로 대신하지 않는다. 순간 변위 0만으로 상쇄라고 말하지 않는다. 완전 상쇄에는 `두 파의 합은 진동하지 않아요.`를 쓴다. 합성 진폭이 0일 때 합성 위상을 0이라고 표시하지 않는다.

| 상황 | 현재 안내 |
| --- | --- |
| 처음 관찰 | 관측할 곳을 눌러 보세요. |
| 전파 방식에서 목표 미리보기 | 손을 떼면 점선 위치로 이동해요. |
| 정지 중 이동 대기 | 재생하면 점선 위치로 이동해요. |
| 실제 파원 이동 / 이후 전파 | 파원이 점선 위치로 이동하고 있어요. / 새 조건의 파동이 퍼지고 있어요. |
| 생략 방식의 미리보기 | 손을 떼면 이 위치로 확정해요. |
| P가 변화 중 | 새 조건이 P에 도착하는 중 |
| 변화 중 간섭무늬 | 변화 중 · 도착 위상으로 본 간섭무늬 |

관찰 도움말은 P에서 큰/작은 진동 찾기 → 펼친 경로차와 간섭 조건 비교 → 순간 변위 0과 지속적 상쇄 구별 → 파장·간격 변경 탐구 순서다. 등진폭·동위상·정상 상태 조건과 λ의 뜻을 설명하고 키보드 안내는 한 줄로 둔다. 잔상·추가 풀이 팝업은 현재 기능이 아니다.

## 7. 교사 수업의 진행과 표현

일반 화면의 `교사 수업` 링크에서 들어간다. 수업 화면은 질문·관찰 무대·수업 조작을 분리하며, `다음` 위치의 버튼에는 다음에 공개할 대상이나 행동을 쓴다. `이전`은 공개 단계를 되돌리고 물리 시간을 되감지 않는다. 오른쪽/왼쪽 방향키와 PageDown/PageUp도 같은 명령을 사용한다.

`멈추고 펼치기`는 누른 순간의 공통 프레임을 정지한 뒤 두 파원을 중심으로 회전한다. 배경만 흐려지며 위로 물러나고, 도착하면 자동으로 확대하지 않는다. 별도의 `나란히 비교하기`로 위치와 행 간격만 바꾼다. 같은 거리 → 추가 경로 → 파장 → 수치 → 성분 → 합은 각각 별도 클릭이다. 연출 중 다음 버튼은 `전환 건너뛰기`이며 한 번의 클릭이 다음 공개까지 겸하지 않는다.

교사 무대는 모든 화면 폭에서 장면별 자동 확대·축소를 하지 않는다. 공간 보기·펼치기·분석·끝점 비교·복귀까지 거리·변위 축척과 선·점·파원 번호 크기를 유지한다. 행 이동은 파형 전체의 평행 이동이며, 화면 크기가 바뀔 때만 공통 축척을 다시 계산한다. 동작 감소 도식도 원래 배율을 유지하고, 두 도식이 함께 들어가지 않으면 앞뒤 보기로 전환한다. 역방향·중단 후 재개에도 같은 규칙을 따른다.

P의 원은 고정된 공간 위치다. 옆의 보라색 변위 표시는 기존 합성점과 같은 요소·같은 값을 사용한다. 펼친 화면의 `같은 P의 두 성분`과 `같은 순간의 거리별 변위` 안내는 두 장소나 시간 그래프로 오해하지 않도록 유지한다. 반 파장 수치는 눈금을 읽을 기회를 준 뒤 공개한다.

`멈추고 펼치기`와 `재생하며 관찰` 외의 단계 이동은 재생 상태를 유지한다. `전체로 돌아가기`는 현재 예제 조건을 유지하고 공간으로 접는다. `수업 처음부터`는 새 실험을 시작한다. 동작 감소는 OS 설정을 따르며 교사가 화면에서 바꿀 수 있다. 변화 과정 대신 같은 축척의 공간·펼침 대응을 표시한다. 실제 구현의 구도와 전환 시간은 `presentation/`에서 관리하고, 일반 모드의 펼치기 규칙은 그대로 유지한다.

완료 검증은 [구현과 검증 상태](implementation-plan.md)의 변경 영역별 검사를 따른다. 버튼 위계 참고: [Geist](https://vercel.com/geist/button), [Atlassian](https://atlassian.design/components/button/).

교사 수업의 8장면·예측 가림·입력 정책·편집과 저장은 [교사 수업 구현](teacher-mode.md)을 따른다. 도구의 교사 메모는 투사 화면에 표시된다는 점을 명시한다. 재개는 저장한 입력으로 시작하는 새 실험이다.

## 8. 실행 실패 안내

자동 복구한 그래픽 오류에는 팝업을 띄우지 않는다. 계속 실행할 수 없을 때만 `시뮬레이터가 멈췄어요.`와 처음부터 시작하는 `새로고침`을 제공한다. 시작 단계의 실패는 `시뮬레이터를 시작하지 못했어요.`로 구별한다. 제목으로 초점을 옮기고, 기술적 내용은 접힌 오류 정보 안에 둔다. `오류 정보 복사`가 거부되면 원문을 펼쳐 직접 복사할 수 있게 한다. 보고서는 자동 전송하지 않는다.
