# Interference

두 파원에서 온 파가 한 지점에서 어떻게 중첩되는지, **경로차 → 도착 위상차 → 합성 진동**을 이어서 보여 주는 중고등학교 수업용 시뮬레이터.

두 경로를 시작점이 일치하도록 펼치고, 각 끝점의 진동과 두 파의 합을 함께 관찰한다. 숫자만으로 간섭 조건을 확인하는 과정을 길이 비교와 움직임으로 이해할 수 있게 만드는 것이 목표다.

파원의 위치·진동 이력에 전파 시간을 반영하는 수업용 시뮬레이터다. 두 파원의 간섭 관찰부터 경로 펼치기, 도착점과 합성 진동 비교까지 브라우저에서 실행한다. `Interference`는 저장소 이름이며 최종 서비스 이름은 정하지 않았다.

## 핵심 경험

1. 두 파원의 간섭 모습을 보고 관측점 P를 움직인다.
2. 두 파원에서 P까지의 실제 경로와 거리를 확인한다.
3. 공간에서 본 길이와 파장을 그대로 유지하며 두 경로가 펼쳐지고, 시작점이 정렬된다.
4. 같은 거리까지의 파형과 추가 경로를 비교해 도착 위상차를 살펴본다.
5. 수평 보조선으로 연결된 두 성분점과 그 아래 합성점에서 P의 진동을 관찰한다.

파동은 기본적으로 계속 진동한다. 사용자가 일시 정지하면 모든 표현이 같은 순간에 멈춘다.

파장을 바꾸면 새로 생성되는 파동부터 바뀐다. 파원을 드래그하는 동안에는 목표 위치만 표시하고, 놓으면 파동 속력의 70% 이하로 실제 파원이 이동한다. 이미 나온 파동은 과거 위치에서 계속 전파된다. 새 조건이 퍼지는 동안에는 단일 파장 비교와 고정된 간섭 판정을 유보한다.

공간과 비교 화면은 하나의 거리 축척을 사용한다. P·파장·파원 간격을 바꿔도 축척을 유지하며, 화면 크기가 바뀌면 두 표현을 함께 조정한다. 데스크톱의 조절기는 옆에, 휴대폰의 조절기는 관찰 화면 아래에 배치한다.

## 실행

Node.js 22.12 이상에서 실행한다.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소를 연다. `npm run build`는 타입 검사 후 `dist/`에 정적 앱을 생성한다. `npm run preview`로 빌드 결과를 확인할 수 있다. 경로를 상대 주소로 빌드하므로 `/interference/` 같은 하위 경로에서도 사용할 수 있다.

## 조작

- 화면을 누르거나 P를 끌어 관측점을 바꾼다. 파원 손잡이는 위아래로 끌어 목표를 미리 보고, 놓아서 이동을 확정한다. Escape로 미리보기를 취소한다.
- `경로 비교`로 두 경로를 펼친다. 펼친 상태에서도 P·파장·파원 간격을 바꿀 수 있다.
- `간섭무늬`는 정상 상태의 합성 진폭 분포다. 변화가 퍼지는 동안은 파동 모습을 보여 주고, 정상 상태가 되면 선택한 진폭 보기로 돌아온다.
- 필드 아래 색상바를 눌러 `간섭 대비`, `푸른 물결`, `은빛 물결`을 고른다. 물결 색상은 골을 어둡게, 마루를 밝게 표현한다.
- Tab으로 손잡이를 선택한 뒤 방향키로 움직인다. Shift를 함께 누르면 이동량이 커진다.
- `일시 정지`는 전파·진동·파원 이동을 함께 멈춘다. 정지 중 목표 지정은 재생할 때 실행한다. `처음으로`는 물리 조건·시간·이력을 초기화하고 선택한 보기와 재생 상태를 유지한다.

## 코드 구성

TypeScript와 Vite를 사용한다. 배경은 WebGL2로 계산·표시하고, 지원되지 않으면 Canvas 2D와 CPU 계산으로 전환한다. SVG·HTML로 조작점·비교부·글자를 그린다. 앱 실행에 필요한 외부 런타임 라이브러리는 없다.

GPU에서는 60fps를 목표로 기기의 처리 여유에 맞춰 배경 해상도를 조절한다. 지속적인 부하에서는 갱신 빈도도 낮춘다. 일시 정지하면 높은 해상도로 다시 그리며, GPU 자원 손실·복구에도 실험 상태를 유지한다. 품질 조절은 물리 시간·전파 속력·수치에 영향을 주지 않는다.

## 검증

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

- 수치·계약 검사: 대표 간섭 조건, 변화 도착 지연과 과거 파동 보존, 지연 시각 독립 검산, 이동 속력·안착, 불변 프레임, 공간·경로·P 대응, 정지·재개, 좌표·축척·펼치기.
- 브라우저 통합 시나리오: 드래그 미리보기·확정·취소·재지정, 정지 중 목표 예약과 파장 변경, 진폭 보기의 전환 표시·초기화, 기존 재생·간섭·키보드·터치·반응형·픽셀 길이 계약.
- GPU 검사: CPU 기준 계산과 세 프리셋의 출력 비교, 장시간 실행·이력 보존, GPU 미지원·셰이더 실패·컨텍스트 손실/복구. 픽셀 읽기는 검증에서만 사용한다.
- Chromium에서 데스크톱·모바일 화면을 확인했다. 실제 Android/iOS 기기 및 Safari에서의 확인은 남아 있다.

## 개발 시작

`AGENTS.md`와 제품 설계를 먼저 읽는다. 기능을 추가할 때 해당 책임의 공개 함수를 재사용하고, 직접 영향을 받는 계산과 화면을 확인한다.

초기 화면은 같은 진동수·같은 초기 위상·같은 진폭의 두 파원이 과거부터 진동한 정상 상태다. 이후의 파장·위치 변경은 이력을 통해 전파한다. 거리에 따른 진폭 감소와 반사는 생략한다. 모든 화면은 같은 엔진 프레임을 사용한다. 향후 격자 파동방정식 백엔드는 `WaveEngine` 계약으로 교체할 수 있으나 현재 구현된 것은 지연 위상 백엔드다.
