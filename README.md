# Interference

두 파원에서 온 파가 한 지점에서 어떻게 중첩되는지, **경로차 → 도착 위상차 → 합성 진동**을 이어서 보여 주는 중고등학교 수업용 시뮬레이터.

두 경로를 시작점이 일치하도록 펼치고, 각 끝점의 진동과 두 파의 합을 함께 관찰한다. 숫자만으로 간섭 조건을 확인하는 과정을 길이 비교와 움직임으로 이해할 수 있게 만드는 것이 목표다.

첫 수업용 MVP를 구현했다. 두 파원의 간섭 관찰부터 경로 펼치기, 도착점과 합성 진동 비교까지 브라우저에서 실행한다. `Interference`는 저장소 이름이며 최종 서비스 이름은 정하지 않았다.

## 핵심 경험

1. 두 파원의 간섭 모습을 보고 관측점 P를 움직인다.
2. 두 파원에서 P까지의 실제 경로와 거리를 확인한다.
3. 공간에서 본 길이와 파장을 그대로 유지하며 두 경로가 펼쳐지고, 시작점이 정렬된다.
4. 같은 거리까지의 파형과 추가 경로를 비교해 도착 위상차를 살펴본다.
5. 수평 보조선으로 연결된 두 성분점과 그 아래 합성점에서 P의 진동을 관찰한다.

파동은 기본적으로 계속 진동한다. 사용자가 일시 정지하면 모든 표현이 같은 순간에 멈춘다.

공간과 비교 화면은 하나의 거리 축척을 사용한다. P·파장·파원 간격을 바꿔도 축척을 유지하며, 화면 크기가 바뀌면 두 표현을 함께 조정한다. 데스크톱의 조절기는 옆에, 휴대폰의 조절기는 관찰 화면 아래에 배치한다.

## 실행

Node.js 22.12 이상에서 실행한다.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소를 연다. `npm run build`는 타입 검사 후 `dist/`에 정적 앱을 생성한다. `npm run preview`로 빌드 결과를 확인할 수 있다. 경로를 상대 주소로 빌드하므로 `/interference/` 같은 하위 경로에서도 사용할 수 있다.

## 조작

- 화면을 누르거나 P를 끌어 관측점을 바꾼다. 파원 손잡이는 위아래로 끌어 간격을 바꾼다.
- `경로 비교`로 두 경로를 펼친다. 펼친 상태에서도 P·파장·파원 간격을 바꿀 수 있다.
- `간섭무늬`는 합성 진폭의 분포다. 무늬가 고정되어도 경로의 파형과 P의 세 점은 계속 진동한다.
- Tab으로 손잡이를 선택한 뒤 방향키로 움직인다. Shift를 함께 누르면 이동량이 커진다.
- `일시 정지`는 모든 파동을 같은 순간에 멈춘다. `처음으로`는 물리 조건과 시간을 초기화하고, 선택한 보기와 재생 상태를 유지한다.

## 코드 구성

TypeScript와 Vite를 사용한다. 화면은 Canvas 2D·SVG·HTML로 구성하며 앱 실행에 필요한 외부 런타임 라이브러리는 없다.

| 위치 | 구현 책임 |
| --- | --- |
| `src/model/` | SI 단위 입력, 기본값, 범위와 상태 변경 |
| `src/physics/waves.ts` | 공통 파동식, 불변 스냅샷, 관측점·경로·장 샘플링 |
| `src/runtime/clock.ts` | 재생·정지와 연속 시간 위상을 소유하는 단일 시계 |
| `src/geometry/layout.ts` | 좌표 변환, 공통 축척, 경로의 회전·이동 |
| `src/visual/svg.ts` | 파형 선·점·0선·변위 막대 등 공통 SVG 요소 |
| `src/views/` | 전달받은 계산값으로 파동장과 경로 비교 표시 |
| `src/ui/` | 학생 문구, 조작부, 포인터·키보드 입력 |
| `src/app/main.ts` | 상태, 시계, 샘플, 화면과 입력의 연결 |

## 검증

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

- 수치·계약 검사 12개: 대표 간섭 조건, 순간 변위와 진폭 구별, 경로 끝값·같은 거리, 장 샘플링, 시계, 입력 범위, 좌표·축척·펼치기.
- 브라우저 통합 시나리오 7개: 재생과 전환, 정지 상태의 입력, 고정 간섭무늬, 정확한 상쇄·보강, 길이 역전, 터치·드래그·키보드, 동작 감소 설정, 공간·비교의 픽셀 길이와 파장 일치, 반응형 배치, 가까운 파원 선택.
- Chromium에서 데스크톱·모바일 화면을 확인했다. 실제 Android/iOS 기기 및 Safari에서의 확인은 남아 있다.

## 개발 시작

`AGENTS.md`와 제품 설계를 먼저 읽는다. 기능을 추가할 때 해당 책임의 공개 함수를 재사용하고, 직접 영향을 받는 계산과 화면을 확인한다.

초기 모델은 같은 진동수·같은 초기 위상·같은 진폭의 두 파원이 만드는 정상 상태다. 거리에 따른 진폭 감소와 반사는 생략한다. 물리 계산과 화면 표현을 분리하고, 모든 화면에서 같은 시계와 계산 결과를 사용한다.
