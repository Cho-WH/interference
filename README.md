# Interference

두 파원에서 온 파가 한 지점에서 어떻게 중첩되는지, **경로차 → 도착 위상차 → 합성 진동**을 이어서 보여 주는 중고등학교 수업용 시뮬레이터.

두 경로를 시작점이 일치하도록 펼치고, 각 끝점의 진동과 두 파의 합을 함께 관찰한다. 숫자만으로 간섭 조건을 확인하는 과정을 길이 비교와 움직임으로 이해할 수 있게 만드는 것이 목표다.

현재는 설계 단계다. 이 저장소에는 개발 지침과 설계 문서가 있으며, 실행 가능한 앱은 아직 포함되어 있지 않다. `Interference`는 저장소 이름이며 최종 서비스 이름은 정하지 않았다.

## 핵심 경험

1. 두 파원의 간섭 모습을 보고 관측점 P를 움직인다.
2. 두 파원에서 P까지의 실제 경로와 거리를 확인한다.
3. 두 경로가 연속적으로 펼쳐지며, 시작점과 거리 축척이 일치한다.
4. 같은 거리까지의 파형과 추가 경로를 비교해 도착 위상차를 살펴본다.
5. 수평 보조선으로 연결된 두 성분점과 그 아래 합성점에서 P의 진동을 관찰한다.

파동은 기본적으로 계속 진동한다. 사용자가 일시 정지하면 모든 표현이 같은 순간에 멈춘다.

## 개발 시작

`AGENTS.md`와 제품 설계를 읽고, 구현 순서의 첫 단계부터 진행한다. 작업하는 기능에 해당하는 세부 문서를 함께 참고한다.

초기 모델은 같은 진동수·같은 초기 위상·같은 진폭의 두 파원이 만드는 정상 상태다. 거리에 따른 진폭 감소와 반사는 생략한다. 물리 계산과 화면 표현을 분리하고, 모든 화면에서 같은 시계와 계산 결과를 사용한다.
